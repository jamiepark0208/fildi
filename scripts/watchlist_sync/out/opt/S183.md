# S183 — Meta-labeling the proven IV/RV put edge (11-10)

Script `analysis/s183_metalabel_puts.py [--label tail|loss]`. AFML ch. 3: primary picks the trade, secondary says skip/size.
Primary = monthly 30-DTE 0.20Δ puts in each month's top half by IV/RV20 (S003 grain): 14,591 trades, 80 months 2020→.
Secondary = HistGradientBoosting / logistic on 11 entry features (iv_rv, iv30, iv_rank_1y, mom20, mom_vs_spy, dist_ma50,
rsi14, oversold_self, fk_proxy, earnings_in_window, spy_m20). Walk-forward: refit each year on trades whose exit is before
Jan 1 (no label overlap); test 2022→. n_indep = 58 test months (episodes).

## Winner pass
Winners = kept puts (84 %), losers = ret < 0 (16 %). The meta-label IS the winner-vs-loser pre-entry comparison, fit on train
only: no feature set separates them out of sample (AUC ≈ 0.50). Losers cluster by month (market-wide drops), not by name —
same as S179 (call win rate flat 25–32 % in every state). The lever is month/regime timing (S054, S101, S172), already live.
Next rule to test: real-quote skew / put-wing richness as a new pre-entry feature family for the secondary model.
