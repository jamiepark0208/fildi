## Findings (High)

- **H1 — Split-factor direction disagrees between the two factor sources.** `scripts/watchlist_sync/analysis/s159_lse_panel.py`, `detect_jump_splits()`: for a 7:1 split, `j≈0.143` returns factor 7 (`split_fraction(1/j)`), while `adjust_ohlcv()` multiplies pre-split closes by `fac` — the correct multiplier is 1/7. `load_splits()` uses `fr/to` from `optlab.splits`. If optlab also has the factor, the two sources cancel and the split ships unadjusted (AAPL 2014 → fake −85% day); if not, pre-split closes are inflated 7× (−98% day). Fix: pin the convention end-to-end with a unit test on known splits (AAPL 2014 7:1, NVDA 2024 10:1). **Unverified prerequisite — one DB query first:** confirm whether `lseg_research.daily_history` closes are split-adjusted; the confirm/validate logic assumes they are, and if LSEG is unadjusted, confirmation rejects all genuine splits and validation rescales by a step-function median.
- **H2 — `confirm_lseg_factor` indexes wrong closes.** L~155: the pre-window uses `enumerate(dates[max(0, i-40):i])`, which starts `j` at 0, so `closes[j]` is from the start of the series, not the pre-window (the post-window correctly uses `start=i`). Confirmation returns False for essentially every genuine post-2016 split; the panel silently falls back to `optlab.splits` completeness. Fix: offset `j` to the window start.
- **H3 — `lseg_validate_frame` can delete a whole post-split regime.** L~292–303: median rescale + 10% drop on a step-function ratio (missed split) — e.g. missed NVDA 10:1 → median ≈0.1, rescale shrinks all post-split closes 10×, drop filter deletes every post-2024 bar. Volume is not rescaled alongside prices. Fix: sanity bounds on factors, rescale volume too, never drop on step-function ratios without split evidence.
- **H1 (grid) — Put exit is one bar later than the stock leg; h=20 puts priced past expiry.** `scripts/watchlist_sync/analysis/s159_rsi_grid.py`: stock exits at close `i+h`, put leg at `c_np_t[i+1+h]` — every put cell is an (h+1)-day hold mislabeled as h-day, theta off by a day. With `PUT_DTE=10`, h=20 puts are marked 10 days after expiry on a floored 1-day remaining life; h=10 exits on/past expiry. All S159 short-put rows affected; h=10/h=20 rows meaningless as priced. Fix: align the put exit to `i+h`, re-run the grid, restate the affected rows.

## Findings (Medium — fix in the same pass)

- **M1** 2:1 splits are mathematically undetectable (skip band `0.48–2.05` contains `j≈0.5`) despite the docstring claiming "jump detect (2:1, 3:1, …)".
- **M2** Crash days can be misread as splits pre-2016 (fail-open confirmation, no factor sanity bounds; negative/≥1000× factors applied blindly, can flip closes negative and wipe pre-split history via `sanitize_ohlcv`).
- **M3** `cmd_build` writes the pickle *before* self-test — a failed validation still ships a corrupt cache.
- **M4** `fetch` never refreshes a cached CSV — the panel freezes at first fetch despite date-stamped filenames.
- **M5** VIX is traded as a stock in "→ all stocks" cells (the stock loop runs over the VIX column too); the put section correctly excludes it. Contamination is concentrated on exactly the stress days being studied.
- **M6** Put marks freeze IV at entry (no vega) — IV crush, a primary short-put profit driver on stress rows, is omitted; returns biased (likely understated).
- **M7** S158: ceiling exit executes at the same close that generates the signal; lift benchmark horizon mismatch (ceiling-exit trades held 1–3 days benchmarked against the 10-day every-day mean).
- **`lse_client.py`:** `get_json` cache has no TTL and can cache a poisoned (non-JSON 200) response forever; `_request` crashes the whole run on transient network errors (only `HTTPError` caught); `Retry-After` parsing can raise `ValueError`; one malformed volume string (`"1,000"`/`"N/A"`) crashes the entire build, no per-ticker isolation.
- **`lse_client_test.py` is stub-level:** pure helpers only, zero coverage of the client, the parser the panel actually uses, or any panel function. H1/M1/H2 would all have been caught by one split-adjustment unit test.
- Already noted in the patch (not new): UNH ships with a known split/adjustment artifact (~4.9% mean 5d base); VIX OHLC fabricated (high≡low≡close, "volume" is a price level).
