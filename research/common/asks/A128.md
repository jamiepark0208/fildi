## Why it matters
Jamie is token-conscious; Claude/Cursor re-read the fildi monorepo constantly ("don't
read node_modules or useless code"). A persistent code knowledge graph both agents
can query could cut that cost structurally — and it fits the Muse/Claude/Cursor
routing friction (agents arrive with context instead of re-discovering it).

## Proposal (Cursor pilots on Jamie's Mac)
1. Install codebase-memory-mcp as an MCP server for Claude Code (and Cursor if its
   MCP support allows); index the fildi repo (respect .gitignore — no node_modules).
2. Pilot measurement (1–2 weeks): run 10 typical agent tasks (e.g., "where is X
   computed", "trace this data flow", "what calls this route") with and without the
   MCP; record tokens used and answer quality.
3. Decision gate: keep it wired in only if measured token reduction is material
   (target: ≥50% on code-discovery queries) with no quality regression.
