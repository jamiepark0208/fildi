## Muse's verification (VM, Nov 7 — test before planning)

- **OpenCode is REAL.** Repo `github.com/sst/opencode`, now `github.com/anomalyco/opencode` (SST renamed to Anomaly). MIT license. ~210,600 stars late Sept 2026 (post's 213K checks out against the Oct snapshot).
- **What it is:** a provider-agnostic terminal coding agent — a HARNESS, not a model. It reads the repo, edits files, runs commands, retains sessions, uses MCP tools, and talks to 75+ providers (Anthropic, OpenAI, Google, Bedrock, Groq, Azure, OpenRouter) plus local models via Ollama / LM Studio / vLLM and custom OpenAI-compatible endpoints. V2 (past 2.0 late Sept 2026): terminal UI + desktop app + browser UI, ACP agent mode for Zed, Build agent + Plan agent (Plan cannot edit files), fine-grained permissions.
- **Why it matters here:** it decouples the harness decision from the model decision. A360 tests the GLM model, A351 tests DeepSeek's harness+model, the Qwen test tests a local model — OpenCode can host ALL THREE behind one interface, so testing it once answers the harness question for every model candidate, and the results stay comparable instead of each model test dragging its own harness along.
- **Fildi-relevant gaps, verified from docs:** V2 reads ONLY `AGENTS.md` — no `CLAUDE.md` fallback. Fildi's agent instructions live in BOTH (`CLAUDE.md` + `AGENTS.md`), so the gap is real and must be tested, not assumed away. V2 also lacks session sharing, LSP diagnostics, and V1 plugins. No Claude Pro/Max login — Claude models need an Anthropic API key or a gateway. The tool is free; models are pay-your-provider (Zen Go plan $10/$40 mo, or BYO API key).

## Muse's analysis

**1st level — what this is.** The open-source, MIT-licensed terminal agent that could replace Cursor's seat as the place where fildi plans get built — with the model swappable underneath (GLM, DeepSeek, Qwen-local, or Claude-by-API-key if Jamie ever approves one).

**2nd level — why it matters here.** Cursor expires Dec 11, 2026 and Jamie will not renew. Every candidate so far is a model OR a bundled harness+model. OpenCode is the only candidate that is harness-only, which is exactly the shape fildi needs: the roster already decides models separately (Claude = quant review, the builder seat = one model), and a provider-agnostic harness means the builder model can change on cost/quality without relearning a tool. If it works, the Dec 11 cliff becomes a model swap, not a tool migration. If the CLAUDE.md gap blocks fildi's instructions, or its builds score below DeepSeek's harness on the same task, it drops cleanly.

## Steps

- **Step 0 — Mac install + instruction-gap test.** Install OpenCode on the Mac (npm or Go, current version). Verify: version, `AGENTS.md` read, and whether the missing `CLAUDE.md` fallback actually blocks fildi's instructions on a real plan (read a plan file, ask it to restate the constraints — if it misses CLAUDE.md-only rules, the gap is confirmed). Verify which model routes are actually available on the Mac WITHOUT a new key: Ollama local first; API routes only if Jamie approves a key. If no model route is available at all, stop and say so — do not proceed on a different model.
- **Step 1 — Real build test, same fixed task as A351 Step 1.** Build a fildi plan task on a test-repo copy so the OpenCode, DeepSeek Harness, and (when run) GLM results are directly comparable. Run it once per available model route (local first; API route only with an approved key). Graded by the code-checked review bar (Muse review: verify every named file and function, run the plan's fixtures through its own math, name what could not be verified). No invented APIs/files in the diff.
- **Step 2 — Cost + latency.** A month of fildi build volume per route: Zen Go $10/$40 vs BYO API keys vs Claude Pro $20/mo vs Cursor. Include measured latency at fildi-real context sizes.
- **Step 3 — Verdict + catalog row.** Adopt (integrated + visible in Settings) or drop (recorded with reason). Never limbo. The settings catalog row is acceptance criteria, not decoration.
- **Stop rule:** Step 1 scores below the A351 DeepSeek result on the same task, or the CLAUDE.md gap blocks fildi's instructions with no repo-side fix, → drop.

## Pass/fail bars

- **P1:** Install works on the Mac; instruction-gap test run and its result named (gap bites or not).
- **P2:** Build test on the fixed A351 task scores ≥ the DeepSeek result on the same task (or within a margin Claude sets in review) AND the diff passes the code-checked review with zero invented APIs/files.
- **P3:** A month of fildi build volume costs ≤ Claude Pro $20/mo on at least one route, or the saving is named and Jamie accepts it.
