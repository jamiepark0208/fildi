## Detail
**Population:** every ticker in `fmp_fundamentals` × every gold field in FIELD_DEFS (ticker_fundamentals + field_provenance). No sampling at L0/L1.

**Layers, cheapest first (stop paying once a row is explained):**
- **L0 identities ($0, all rows):** P/E = close ÷ EPS, P/S, P/B, EV = mcap + debt − cash, margins = item ÷ revenue, ROE/ROA numerators, growth vs the two stored periods, sign and unit sanity (%, ×, thousands vs units), share count vs mcap ÷ price, ADR ratio, statement currency, age vs the latest 10-Q/10-K date (stale = older than the newest filing).
- **L1 cross-source ($0):** gold vs every stored vendor value (source_fundamentals, vendor_raw). Flag material disagreement with FIELD_DEFS tolerances.
- **L2 truth (SEC companyfacts, free, ≤ 8 req/s, cache in vendor_raw):** every L0/L1 flag + a random 5 % of clean rows (gives an error rate with a 95 % CI for the "clean" part). FactSet only for what SEC can't settle (foreign filers, non-GAAP), within the existing daily FactSet budget.
- **L3 explain + prevent (per error class, not per row):** group flags into classes (wrong period, currency mix, ADR scaling, NCI vs to-common, stale pull, vendor unit bug, split not applied, stand-in 0, two pickers). For each class: root cause with evidence (filing tag + accession, vendor payload), the producer line that let it through, a guard (FIELD_DEFS / merge-trusted / fetcher), a regression test case, and a `recurring-bugs.md` row.

**Outputs:**
- Table `audit_findings` (ticker, field, gold, truth, truth_source, class, root_cause, evidence, fix, status).
- `out/audit/A326.md`: counts by class and field, the names each class touches on today's Model List and fund scores, and the top 20 by impact for Claude to judge.
- Settings › Stock DB "Audit" chip per cell (class + why on hover). UI is phase 2, after the numbers.

**Acceptance:**
1. 100 % of name × field rows get an L0+L1 status.
2. SEC-sample error rate reported with CI.
3. Every class has root cause + guard + test.
4. A re-run after fixes shows each class at 0 or with a written reason.
5. Smoke first: 10 names (AAPL, BABA, TSM, TCOM, KKR, TKO, C, ASML, RKT, a small cap), every flag hand-checked.

**Budget:** $0 vendor at L0/L1; SEC free; FactSet only for residue. Fund rescore only after the fixes and Claude's pass.
