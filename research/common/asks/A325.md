## Ask
NVDA reports 11-17 (after the close). A semis put whose life spans that date, for example the MRVL 145p expiring 11-20, carries NVDA event risk that the per-name earnings gate (S066) can't see. Question: on non-reporting semis, do ~30–45 DTE short puts that span an NVDA print breach more often or earn less per $ of risk than the same names' puts over windows with no NVDA print? If yes, the put book needs a "leader print inside the window" flag. If no, the NVDA date is noise for semis puts and S066 stays enough.

## Detail
- **Universe:** GICS semis + semi-equipment sub-industries from `research_common.security_class` (not `ticker_registry.sector`), plus SMH itself as a row. Drop NVDA. Drop any name whose own earnings fall inside the window (S066 already handles those), and report how many that removes.
- **Events:** every NVDA earnings date since 2012 (IBES `anndats` or LSEG, give the source). Sessions after the close map to the next session.
- **Trades:** S081 engine. Black-Scholes at iv30 × S075 skew. Entry on each Friday; ~0.25Δ and ~0.15Δ puts at 30–45 DTE, held to expiry; fill = mid − 23 % of spread; excess over T-bill. **Spanning** = NVDA print between entry and expiry. **Control** = same names, same delta/DTE, windows with no NVDA print and no own print.
- **Outputs (both deltas):** n, breach rate (close < strike at expiry), mean and median P&L per $ of cash-secured risk, worst 5 %, month-block t on the spanning-minus-control gap. Also: did entry IV already price it (spanning entry iv30 − control entry iv30)? A breach gap the IV already paid for is not an edge.
- **Controls:** (1) SMH 20-d return regime: split into after a ≥ 9 % 2-session drop (S149 condition, today's state) vs all others, and report n even when small. (2) Beta: run the same spanning-vs-control test on a non-semi comparator group (GICS software, same NVDA dates), so a gap that is only "NVDA days move high-beta tech" shows up.
- **Pass:** 0.25Δ spanning breach rate ≥ control + 4 pts **and** P&L per $ lower with month-block t ≤ −2 **and** the gap survives the software comparator (semis gap minus software gap still ≥ 3 pts). **FAIL** = no flag; the result goes into INDEX and A325 is closed. No substitute leader (AVGO/TSM) gets promoted post hoc. Name it as a follow-up row instead.
- **Smoke test first:** 5 names × 2 NVDA prints, one trade hand-checked against a real Polygon or Schwab close if cached.
