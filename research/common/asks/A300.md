# A300: Repair — macro-themes imports readChartsCacheFile/readMacroCacheFile that macro-cache never exports (Key Themes dead, CI typecheck red)

**Moves:** ops

## Ask
`macro-themes.ts` (new in 79ccafdf, the Macro › Key Themes tab) imports two helpers
from `./macro-cache.js` that do not exist in that module, so the Key Themes route,
the daily themes snapshot, and the explain-context enrichment that reads them
cannot load. Add the missing helpers or drop the fallback — do not paper over it
with `as any` or `ts-ignore`.

  `readChartsCacheFile, readMacroCacheFile` from `./macro-cache.js`, and `:291`

  macro: loadMacroCache() ?? readMacroCacheFile()`.

## Fix direction
Either (a) add `readChartsCacheFile()` / `readMacroCacheFile()` to
`macro-cache.ts` — read + JSON.parse the underlying cache files, returning
`null` on missing/corrupt files, with return types matching what `loadChartsCache`
/ `loadMacroCache` return so the `??` fallback typechecks; or (b) drop the
fallback and rely on `load*Cache()` alone, if those already read the files.
Prefer (a) only if the fallback semantics (bypass TTL/staleness) are intended;
otherwise (b) is the smaller change.
