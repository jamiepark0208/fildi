## 1. Problem (repo-watch finding, 2026-11-05 evening run)

`turning_points.py main()` refuses to write scores when the holdout month-high top-decile lift is below 1.5 — but `holdout_month_high_lift()` returns `float("nan")` for a degenerate holdout (fewer than 500 holdout rows, fewer than 5 top-decile rows, or a zero/negative base rate), and `nan < 1.5` is `False` in Python. So the exact case the gate exists for — validation failed or unmeasurable — sails through and writes `turning_point_scores` from an unvalidated model. (`--holdout-check` mode is not affected: `nan >= 1.5` is `False`, so it exits 2.)

Severity: low. Requires a degenerate holdout to trigger, and the nightly step is soft (`daily.py` swallows failures). But a gate that passes on NaN is worse than no gate: it reports success while writing scores the validation could not support.

## 2. Evidence (branch cursor/mac-dev @ caa1c44)

- `scripts/watchlist_sync/turning_points.py`, `holdout_month_high_lift`: returns `float("nan")` when `hold.sum() < 500`, `top.sum() < 5`, or `y.mean() <= 0`.
- `scripts/watchlist_sync/turning_points.py`, `main()`: `if lift < 1.5: ... sys.exit(2)` — NaN fails this comparison, execution continues to `score_day` + upsert.
- `scripts/watchlist_sync/daily.py`: turning-points step is `... 2>&1 | tail -2 || echo 'turning points skipped'` (soft), so a gate failure would only skip the day's scores — the NaN path is the only way unvalidated scores land.

## 3. Fix direction

Treat NaN as a failure at the gate: `if lift != lift or lift < 1.5: sys.exit(2)` (or `math.isnan(lift)`), with the STOP message naming NaN explicitly. Same treatment in `--holdout-check` for consistency (it already exits 2, but the message should say the lift was unmeasurable, not a number below bar).

## 4. Pass / fail

- Unit test: `main()` (or the gate predicate) exits non-zero when `holdout_month_high_lift` returns NaN — no rows written to `turning_point_scores`.
- Existing behaviour unchanged: lift ≥ 1.5 writes scores; 0 < lift < 1.5 exits 2 with the STOP message.
- `turning_points.py --holdout-check` on a degenerate holdout exits 2 and prints that the lift was unmeasurable.
