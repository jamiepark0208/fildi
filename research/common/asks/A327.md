## Detail
1. **Week-clustered evidence:** every live stat is computed by expiry week (month-block for backtests); nothing updates on fewer than 6 distinct weeks. The scoreboard shows n trades and n weeks.
2. **Grade what we rejected:** plan_items already stores L1-failed rows with contract + checks. grade_ledger grades them at expiry like shown ideas (folder `blocked:<gate>`). Per gate: kept-vs-removed P&L, breach, worst 5 %. A gate that removes winners shows up.
3. **Prior from history, posterior from live:** each rule/weight carries its backtest result as a prior (beta-binomial for breach, normal for P&L/wk, effective n = 20 weeks). Live weeks update it weekly.
   - Promote a challenger only when P(better than champion) ≥ 0.9.
   - Demote a rule to shadow when P(below its floor) ≥ 0.9 after ≥ 6 weeks.
   - Floors and promises live in strategy_rules.json next to each rule.
4. **Replay test before going live (uses history, no waiting):** run the v2 loop weekly over 2021-01 → 2026-10 on the backtest engines (S059/S101/S102 put sims, S081 options). It must:
   - (i) keep Q5 put edge;
   - (ii) demote any rule whose live posterior is below its floor (amended 11-05: S109 rich puts PASS, so they are not expected to demote);
   - (iii) promote ≤ 1 change/month;
   - (iv) show the weight path converging, not oscillating.
   Report as a chart + table.
5. **Churn fix:** find why w_iv_rv starts back near 0.55 each cycle (renormalization vs stored champion). Promote only when a change repeats 2 cycles and moves the decision on ≥ 5 % of names; max 1 promotion/week.
6. **New signals enter as challengers:** A328 output (turning-point scores) plugs in as shadow challengers graded by the same machinery. Nothing ships without the posterior bar.
7. **Autonomy + budget:**
   - Runs inside daily.py (already scheduled). $0 vendor calls (uses stored closes/quotes).
   - One digest line per day in agent_start / Settings › Agents: what changed, what got demoted, why.
   - Claude reads only that line unless something changed.
