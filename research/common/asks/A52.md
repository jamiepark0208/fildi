## Detail
Build a user-assumption-driven free-cash-flow model whose outputs blend with learned per-stock characteristics into customized model scores that improve continuously. Components (plan-level): (1) Assumption layer — user sets per-ticker/sector assumptions (revenue growth, EBIT margin path, capex intensity, WACC, terminal growth); versioned assumption sets; UI panel to view/edit/override. (2) FCF engine — standardized projection (revenue → EBIT → NOPAT → FCF incl. capex + working capital → discount → firm/equity value); inputs from FMP statements + IBES estimates; recompute on new filings/estimate revisions, not on a poll. Builds on the existing fair-value surface. (3) Characteristic learning — per-ticker profiles learned from price/volume history: support/resistance (swing highs-lows, volume-at-price, round numbers), vol regime, gap behavior, earnings drift, drawdown-recovery speed; stored with confidence + last-updated; refreshed on price updates. (4) Custom scores — blend: FCF value gap + characteristics (e.g. distance-to-support as entry timing) + event risk (A49/A51) + premium; per-ticker weights learned from prediction errors. (5) Feedback loop — track predictions vs realized (did support hold? did the FCF thesis play out over quarters?) and adjust characteristic weights; persistently wrong characteristics quarantined per A47 survival logic. Acceptance: assumption UI edits change scores; FCF values for the coverage universe; characteristics visible per ticker with confidence; prediction-error tracking live. Cost: reuse existing vendor quota; compute on data-change events. Approval gates: assumption defaults and any score-weight changes need user sign-off (AGENTS.md).
