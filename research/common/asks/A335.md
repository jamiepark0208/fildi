## Ask
Jamie 11-04: reverse-engineer winners. For each day in the last ~42 sessions, find the biggest intraday swings in the 61-name grading universe and ask which indicator signal (if any) fired at or just before the swing started, and in which direction. The scorecard measures signal → outcome (precision); this measures swing → signal (recall), so a signal that is rare but catches the big ones shows up.

## Detail
- **Swings (no look-ahead in labels' use):** per ticker per day on 5m RTH bars (`fetchIntradayHistory` / the same Yahoo 5m the grader uses), turning points by zig-zag ≥ 1.5 ATR(14); keep each day's top 3 swings by size in ATR. Label = start bar, direction, size, duration.
- **Catch:** an `indicator_events` row (any tf) for that ticker with matching side within [start − 3 bars, start + 2 bars] (5m bars). Report recall = caught / swings, per indicator and kind; precision = share of that indicator's events that start a top-3 swing; base rate = same for random bars (vol-matched, `preMove`).
- **Context filters to test (each, both halves):** time of day bucket, SPY+QQQ same-side signal within 10 min (market-wide), squeeze-on state, multi-tf agreement (5m + 15m same side). Pre-register: a filter "helps" only if precision lift ≥ 1.5× base and the pair holds in both halves with n ≥ 50.
- **Output:** `research/studies/S153-swing-reverse-engineer.md` + INDEX row + ≤ 20-line packet here: recall/precision table, best 3 filters, 3 example days with times (PT). No app code changes.
