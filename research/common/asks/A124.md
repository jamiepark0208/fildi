- Structure matches claims: `engine/oracle.py` (forecast engine), `engine/swarm.py`
  (4-persona debate), `engine/ledger.py` (Brier-scored track record — 11 code hits),
  `engine/mcp.py` (MCP bridge), `engine/healthscore.py` (1–100 global score).

- Full live run NOT tested in sandbox (needs Ollama + model download) — the pilot
  below is the live test.

## Why it matters for fildi
Pythia produces Brier-scored probabilistic forecasts with reasoning attached — the
same calibration philosophy as A85 (pundit tracker) and the natural cross-check for
A82 (prediction markets: Pythia odds vs Polymarket/Kalshi odds on the same events).
A morning-brief digest + probability drift tracking also fits the macro tab.

## Proposal (Cursor builds; runs on Jamie's Mac, not the cloud VM)
1. Deploy Pythia locally via the Coolify/Docker path (Pljas/pythia-coolify) or direct
   `PYTHIA.command`, with Ollama + a capable local model.
2. Pilot study (2–4 weeks): log Pythia's daily forecasts on 5–10 macro/market questions
   (Fed moves, CPI prints, SPX direction) alongside Polymarket-implied odds for the
   same questions. Score both with Brier scores.
3. Decision gate: adopt as a forecast input for A82/A85 only if Pythia's Brier score
   beats or complements prediction-market odds net of cost (compute is local, so the
   bar is calibration quality, not price).

## Out of scope
- No Hummingbot, no OpenOutreach.
- No cloud LLM spend for the pilot — Ollama-local only. Paid APIs only with Jamie's OK.
- Forecasts are inputs to human review, never auto-traded (no-AI-trading rule).
