## 1. Problem (repo-watch finding, 2026-11-05 evening run)

`technicalHash` (the `hashInputs` for the technical explain surfaces, i.e. the explanation cache key) includes the S151 turning-point line only as its character length: `` `_tp${d.turningPointLine.length}` ``. Two different turning-point lines with the same length — e.g. probabilities moving 12.4% → 13.4% while the rest of the line is unchanged — hash identically, so a cached explanation generated under the old TP context is served as current. The prompt tells the model to weave the TP line in, so the stale line can surface verbatim in the bullets.

Severity: low. Only the cached explanation text is affected (scores are untouched), and the TP line is context, not an input. But the hash exists precisely to bust the cache when inputs change, and it fails to do so for this input.

## 2. Evidence (branch cursor/mac-dev @ caa1c44)

- `artifacts/api-server/src/routes/explain.ts`, `technicalHash`: `const tp = d.turningPointLine ? `_tp${d.turningPointLine.length}` : "";` — content-independent.
- `artifacts/api-server/src/routes/explain.ts`, surfaces: `hashInputs: (_b, d) => technicalHash(d)` on `technicalPutSurface` / `technicalCallSurface`.
- `artifacts/api-server/src/lib/turning-point-scores.ts`, `formatTurningPointLine`: the line embeds `prob`/`base`/`decile` numbers that change daily while the string length often stays the same (e.g. `12.4%` → `13.4%`).

## 3. Fix direction

Hash the line's content, not its length — include the line itself in the hash string, or a short content hash of it (same pattern as `fundamentalHash`, which embeds the values). Keep the `_tp` prefix so absence (`null`) still hashes distinctly from presence.

## 4. Pass / fail

- Two `TechnicalData` payloads identical except for the turning-point probabilities produce different `technicalHash` values; identical payloads produce identical hashes.
- A `/explain/score` call after the TP line changes (same length, different numbers) returns a freshly generated explanation, not the cached one.
- Existing explain tests / CI green.
