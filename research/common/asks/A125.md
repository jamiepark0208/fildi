## Proposal (Cursor builds)
New "Video Lab" tab (name TBD — Video Lab / Shorts Lab):

**1. Video library**
- Upload mp4 test videos (local file store, reuse existing upload infra if any).
- Grid with thumbnail, title, hook line, topic tag, date, status (draft / testing / published).
- Inline preview player; delete/rename.

**2. Idea generator (Muse co-creation)**
- Input: niche/topic + optional angle.
- Output: 10 hooks (stat-based all-caps style per the @marc.kaz formula), each with a
  3-beat script outline (hook → demo → CTA).
- LLM: reuse whatever the app already uses; Ollama-local preferred (free, matches the
  MoneyPrinterTurbo pipeline).
- Save ideas to a backlog; promote an idea to "in production."

**3. Idea ↔ video linking**
- Attach a rendered video to an idea; track iterations (v1, v2…).
- Per-video notes: what worked / what flopped; simple 1–5 rating.
- Optional later: manual performance entry (views, likes, saves) or platform API pull.

**4. MoneyPrinterTurbo bridge (phase 2, not v1)**
- Export an idea as a MoneyPrinterTurbo topic/keyword input; import the rendered mp4
  back into the library. Keep it manual copy-paste in v1 — no deep integration until
  the workflow proves itself.

## Out of scope (v1)

- No analytics dashboards beyond manual entry.
- This tab is Jamie's side-project workspace; keep it out of the investment data paths.
