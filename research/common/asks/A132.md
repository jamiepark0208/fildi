## Context
From @startscalr_sohum's reel (calls it "FincorpTerminal"; actual product is
**FinceptTerminal** by Fincept Corporation). Verified 2026-10-16: 32.5K stars,
active (pushed 2026-10-13), v4.0.3, C++20/Qt6 desktop app (Win/macOS/Linux).
Open-source "Bloomberg alternative" — not a library to adopt, a competitor to learn

editor, AI Quant Lab (ML, factor discovery, RL), 50+ indicators, global news/sentiment.

## Why it matters
Fildi and FinceptTerminal solve the same problem differently (fildi: put-seller's
web copilot; Fincept: broad retail terminal). A teardown finds proven features fildi
lacks — directly useful given Jamie's "my ui needs much improvement."

## Proposal (Muse does the teardown; Cursor builds only what survives)
1. Feature inventory of FinceptTerminal (install the macOS build or read source):
   catalog every major surface — data connectors, agents, QuantLib modules, charting,
   workflows, Quant Lab.
2. Gap analysis vs fildi: for each Fincept feature, mark **fildi-has** / **fildi-gap** /
   **not-applicable** (e.g., 16 Indian brokers = N/A; QuantLib pricing = maybe).
3. Rank the gaps by (a) fit for a put seller, (b) build cost, (c) differentiation.
4. Output: ranked steal-list with one-paragraph spec each — filed as follow-up ASKS
   rows only for the winners. No wholesale cloning.

- Copying broker integrations or regions irrelevant to Jamie.
