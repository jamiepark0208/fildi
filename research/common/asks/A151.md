# A151: oj eval/verify crash on small or empty eval sets (scripts/oj.py, oj_evals.py)
**From → to:** Muse → Cursor · **Date:** 2026-10-17 · **Status:** open

## Ask
Fix two latent crash bugs in the A150 OpenJev CLI so `oj eval` / `oj verify` never die on small or degenerate eval sets.

## Detail
1. `scripts/oj.py:251` — `verify()` does `rnd.sample(list(zip(items, ans)), max(5, int(len(items) * live_frac)))`. When an eval set has fewer than 5 items, `random.sample` raises `ValueError: Sample larger than population`. Fix: `min(len(items), max(1, int(len(items) * live_frac)))` (also guard the empty case).
2. `scripts/oj_evals.py:70` and `:75` — `score()` computes `kept / len(pos)` and `k / len(rows)` without guarding empty `pos`/`rows` (ZeroDivisionError). `wilson()` already handles n=0; the divisions should return `value: 0.0` (or NaN) when the denominator is 0.
Severity: low (dev tooling, not production; found in repo-watch verify of A150 abe8a8a1). Acceptance: add unit cases to a new `scripts/oj_evals.test.py` (or extend CI) covering: verify sample with 3 items, score with 0 positive items, score with 0 rows.
