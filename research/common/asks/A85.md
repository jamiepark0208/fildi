## Research headline
- **No active service scores pundits' public calls — the gap is real.** Dub/Autopilot track
  *positions* (lagged 13F/Congress filings), never spoken views. PunditTracker is dead; best template
  is an open-source Next.js + LLM auto-grading clone (no data pipeline).
- **Data is collectable**: YouTube transcripts (free — best for CNBC appearances), X API
  (pay-per-use ~$0.005/post read; tracking 15–20 accounts is affordable), Substack RSS (free),
  Fed speeches (federalreserve.gov, polite scraping, no API), SEC 13F free JSON APIs (compare their
  *talk* vs disclosed *puts* — options ARE reported), congressional trading free dataset.
  Bank research notes are paywalled — track strategists via media appearances instead.
- **Scoring blueprint**: CXO Advisory graded 6,582 forecasts by 68 forecasters → 46.9% aggregate
  accuracy; most pundits indistinguishable from chance. Pipeline: extract (asset, direction, horizon,
  confidence) → resolve vs market data at horizon → Brier score + hit rate. **Benchmark every call
  against Kalshi/Polymarket prices at claim time** — markets beat pundits.
- **Key voices for a vol seller**: Tom Lee (CNBC + Fundstrat YouTube + X), Amy Wu Silverman / RBC
  derivatives (CNBC Squawk Box — highest-signal for a put-seller), Mark Cabana / BofA rates,
  Paul Tudor Jones (rare CNBC, explicit probabilities — ideal for scoring), El-Erian, Siegel,
  Dan Ives / Wedbush, Larry Fink (sparse, structural), Fed officials + Treasury.

## Reviews

**Claude plan 2026-10-14 (user asked for it; narrowed to what can be scored honestly):**
*Point:* know which voices are worth listening to. The constraint is statistics:
- **Telling a 60%-right figure from a coin flip at 95% needs ≈ 96 resolved calls per figure** (n ≈ 1.96² × 0.25 / 0.10²).
- Most figures make 5–20 explicit, resolvable calls a year, so per-figure Brier scores stay inside chance for years. CXO's 6,582 graded forecasts averaged 46.9%.

The leaderboard must show that uncertainty, or it will crown noise.
1. **Scope:** ~10 figures who state explicit, checkable calls (level/direction + horizon), e.g. Paul Tudor Jones, Tom Lee's year-end targets, RBC derivatives desk, Fed officials (dot plot / rate path). Free sources only: YouTube transcripts, Substack RSS, Fed speeches. **No X API** (paid, mostly unresolvable chatter).
2. **Scoring:** extract (asset, direction, level, horizon, confidence) → resolve on prices at horizon → hit rate + Brier with **empirical-Bayes shrinkage to 50%** (reuse the `model-track-record.ts` EB pattern). Show "n calls · 90% CI". Badge "skill" only when the CI excludes 50%. Benchmark each macro call against the Kalshi/Polymarket price at claim time (A82 display feed).
3. **Seed priors:** CXO's published per-guru grades (where the figure overlaps) as each figure's prior, so day-1 badges aren't empty or fake.
4. **Dropped:** talk-vs-book via 13F. Filings lag 45 days, show quarter-end snapshots only, and put rows are reported at underlying notional with no hedge context, so "bullish talk, bought puts" can't be called hypocrisy reliably. The sector map from NER keyword dicts is also dropped (noisy); use the figure's explicit asset only.
5. **Where:** Macro tab › Voices: one row per figure (latest call, open calls, record with CI). Replace `BankCard` LLM stances only for figures actually tracked.
