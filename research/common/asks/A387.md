## Ask
Re-point the grade in `dcf/grade.py` (and its callers) from rank IC vs returns to realized option-trade P&L: does the score pick long-call / short-put trades that pay, on real fills, at conditional entries (post-crash, panic)? Rank IC stays as a diagnostic, never the verdict. Jamie ordered this #4 on 2026-11-08: "scores barely move and IC vs returns is not the task."

## Thesis (why)
The Oct 28 audit found the option score's information coefficient is about 0 — and the grade path still tests rank correlation vs returns, a test the score structurally cannot pass and Jamie says is not the task. That mismatch cuts both ways: it can condemn a score that actually pays (A352's champion earns +11.8 bp/wk vs +0.2 random on realized put P&L, invisible to IC) and it can bless a score with a flattering IC that never survives a fill. Re-pointing the grade to realized trade P&L turns the score from an unmeasurable ranking into a falsifiable trade picker — and it aligns the grade with A380, which will report rules on real fills weekly. If the grade and A380 disagree, Jamie gets two truths; this row makes them one.

## Why now
- Jamie ordered it #4 (state.md, 2026-11-08 late) — explicit go-ahead, unstarted.
- A352 just proved the method exists on fildi data (grade puts within each expiry on realized P&L; champion +11.8 bp/wk, 299 weeks, vs random +0.2) — the new grade path can reproduce a known result instead of inventing one.
- A380 (planned) will grade BOARD rules on real fills weekly; the grade function should measure the same thing A380 reports, or the two verdicts will diverge in public.

## Use cases (each with why + expected value)
1. **dcf/grade.py reports realized option-trade P&L per score bucket.** Jamie sees whether top-score names actually pay, bucket by bucket, instead of a correlation coefficient. Expected value: the score earns trust or loses it on money, not on a statistic.
2. **Conditional entries graded as trades, not ranks.** Post-crash / panic entries (S054, S101, S159) are graded on the trades they produce — the same lens as A365/A366. Expected value: the grade answers the question Jamie actually asks before selling premium.
3. **IC demoted to diagnostic.** Kills both misreads at once: "IC ≈ 0 therefore the score is useless" and "IC > 0 therefore it trades." Expected value: no more verdicts drawn from a number that never measured the task.

## Downstream impact
- Every score grade (option score first, then fund/technical scores if the pattern holds) reports P&L-per-bucket; A380's weekly rule grades and the score grade finally agree on what "works" means.
- No change to how scores are computed or to any live pick in this row — the test changes, not the score. A second row promotes any score change the new grade justifies.

## Risks
- P&L grading needs fills/marks: thin names and wide spreads can dominate → S155 half-spread convention + ex-top-ticker check, both stated on the report.
- Survivorship in the grade sample (names that died leave the universe) → state the universe + dates on every report.
- Touching grade code near live scores → this row changes the test only, never the score; any score change needs its own row + Jamie go.
- Scope creep into "fix the score" — out of scope here by design.
