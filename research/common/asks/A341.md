## 1. Goal

A 10-second starter-pack reel lists the quant research stack in five cards: find ideas (SSRN, arXiv, Alpha Architect), understand the theory (López de Prado's *Advances in Financial Machine Learning*, Chan's *Quantitative Trading* + *Algorithmic Trading*), get data (Yahoo Finance, Kaggle, Databento), build + backtest (NautilusTrader, QuantConnect, VectorBT), research tools (OpenBB, KDB-X, Jupyter). Most of it fildi already has or has filed (OpenBB = A333; arXiv q-fin = AI radar; Yahoo = live source, ranked last). The new, testable items are two backtest engines, one data vendor, and one set of validation methods. This row tests each and ends each in adopt or drop — never limbo.

## 2. Muse 1st-level analysis

The reel is a shopping list, not a strategy — so the plan is a stack evaluation, not a study. Muse tested the two installable engines on the VM tonight and both work: NautilusTrader 1.231.0 installs, imports, and runs a backtest engine over 500 SPY daily bars end to end; VectorBT 1.2.0 installs, imports, and runs a 20/50 SMA crossover over 8,500 SPY bars (87 trades, 50.6% win, +548% total, Sharpe 0.63) in 6.7 seconds including import. The question is not whether they run — it is whether either beats fildi's Backtest Lab (A331, Python runner) on a real fildi workload, and what each is for. Databento could not be tested without an account (no key created) — it is carried as a costed probe needing Jamie's key decision, not as a verified tool. The theory leg is only worth anything if it lands as code: AFML's triple-barrier labeling, purged cross-validation, and deflated Sharpe ratio are concrete methods that plug straight into the validation checklist A340 proposes — that is the deliverable, not a reading list.

## 3. Muse 2nd-level analysis

- **Already-covered check (verified in the repo index + file tree):** zero rows mention NautilusTrader, VectorBT, Databento, QuantConnect, KDB-X, López de Prado, purged CV, triple-barrier, or deflated Sharpe. ("kdb" tree hits are all `stockdb` — false positives.) OpenBB is the one overlap and it already has its row (A333). SSRN/arXiv/Alpha Architect have no row as sources; arXiv q-fin is already a radar source, SSRN and Alpha Architect are not.
- **Engines are not interchangeable — the comparison must name a role per engine.** VectorBT is vectorized and fast (6.7s for 8,500 bars) — built for parameter sweeps. NautilusTrader is event-driven with a fill model — built for realistic simulation. Fildi's current runner is neither fast nor fill-realistic, and S155 showed real Polygon prints price signals at 0/60 — mid-mark pricing inflates signals, which is exactly the gap a fill-model engine closes. A verdict of "adopt both" is only honest if each gets a named workload; otherwise one of them is limbo.
- **QuantConnect, KDB-X, Jupyter are assessed, not tested — and mostly dropped.** QuantConnect is a cloud backtesting platform; fildi already has its own Backtest Lab and a put book QuantConnect's generic engine does not model better — drop unless the engine comparison finds a gap the local engines cannot meet. KDB-X is enterprise time-series infrastructure; fildi runs Postgres and its data volumes do not justify a kdb+ stack — drop unless a tick-analytics gap is demonstrated. Jupyter is a workflow choice for the research lane, not a fildi build — no row, no verdict needed; researchers can already use notebooks against the same Python code.
- **Databento's value is honest OOS pricing, not more data.** Fildi already has Schwab/Yahoo/FMP/Polygon/LSEG/WRDS. Databento's edge is clean historical tick + options data at pay-as-you-go prices. Its probe must be costed (one options series + one tick series, price stated) and compared against Polygon/Schwab golden source — a data vendor that cannot beat the golden source on a named series is a drop.
- **The books are inputs, not deliverables.** AFML + Chan are theory; the plan adopts three AFML methods as checklist items and re-grades one past study under them. If Step 3 ships without a re-graded study, it shipped a citation, not a method.
