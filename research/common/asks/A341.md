## Fast screen spec (Claude 2026-11-06) — Jamie 11-06 "studies too slow; reuse known strategies + engines"
Build `scripts/watchlist_sync/analysis/fast_screen.py` (numpy/pandas, no new deps; VectorBT not installed → VectorBT verdict = drop unless numpy misses the time bar). Purpose: screen a strategy library in minutes; only survivors get a full study.
1. **Bars:** `pattern_lab.load(None)` once → wide ticker×date matrices (o,h,l,c,v), cached `~/.fildi/cache/fast_screen_bars.pkl` (rebuild flag). LSEG daily = 2018-10 → today, ~940 names.
2. **Library** (dict id → vectorized signal fn → bool entry matrix + exit rule): triple_rsi5 (A339: RSI(5)<30? use A339.md exact rule, 3 declining days), rsi2_connors (RSI(2)<10, close>SMA200, exit close>SMA5), zscore20 (z<−2 vs RSI(2) twin), overnight (hold close→next open) vs intraday (open→close), gap_down_2pct (continuation vs reversal), gap_up_2pct, rsi_rotation (cross-sectional top-decile RSI(14), weekly rebalance), pead (earnings day from `lseg_research.earnings_moves`; top/bottom reaction quintile, hold 5/21d — check cols with `scripts/dbcols.sh`), 52w_high_breakout. Each fn ≤ 15 lines; library easy to extend (A348/A339/A350 add rows).
3. **Both sides:** every cell long + mirror short (sign flip), never one side only.
4. **Execution:** signal at close t, entry next open t+1 (pre-registered); close-to-close only as a sensitivity column. Holds {1,5,10,21} or rule exit. Cost 5 bp/side.
5. **Comparators:** (a) random entries — same tickers, same count per month, same hold, 200 draws → pct beaten + mean; (b) unconditional same-hold mean; (c) T-bill (reuse `a352_score_rank.load_tbill/tbill_at`).
6. **Splits:** fit ≤ 2022-12-31, val 2023–2024, holdout ≥ 2025-01-01 (pattern_lab constants). Per split: n, mean excess vs random (bp), month-clustered t (`pattern_lab._month_cluster_t` style), win %.
7. **AFML gate:** deflated Sharpe with n_trials = total cells screened; PBO via CSCV (16 blocks) over the cell set.
8. **Survivor rule (pre-registered):** holdout excess > 0 AND fit+val month-clustered t ≥ 2 AND DSR ≥ 0.95. Everything else = "screened out" with the number, not "fail".
9. **Output:** `research/studies/out/fast_screen/<date>.csv` + `.md` (best cell first, then survivors, then top 10 by excess; ≤ 40 lines). CLI: `run [--strategies a,b] [--tickers ..] [--rebuild]`, `self-test`.
10. **self-test:** (i) triple_rsi5 on SPY 2018→ equals a plain per-bar Python loop exactly (trades, avg ret); (ii) report SPY 2018→ triple_rsi5 n/win/avg next to A339's 2015–2026 subsample (36 tr, 80.6 %, +0.89 %) — direction match, not exact; (iii) look-ahead probe: shift signals 1 day earlier → excess must not improve; (iv) random draws reproducible (seed).
