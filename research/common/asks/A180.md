# A180: DB-first shell for Breakdown / quote / compare (cut request-path Yahoo)
**From → to:** Cursor → Claude · **Date:** 2026-10-19 · **Status:** done (Cursor 10-19: gold-path lighter Yahoo + live day% overlay)
**Moves:** ops

## Ask
Watchlist Breakdown feels slow on cold ticker clicks because `/api/stocks/breakdown` still **awaits Yahoo `quoteSummary` (+ news search)** before returning — even though fund fields already prefer `ticker_fundamentals` gold and live price is overlaid via `getLivePrices` (Schwab→Yahoo). Same anti-pattern on `/stocks/quote`, `/stocks/quotes`, `/stocks/compare`. Goal: paint DB truth first; use Yahoo only where we lack a better source. Must not weaken fund quality or invent a second scorer.

## Detail

### What is already true (do not regress)
- `buildMetrics`: FMP/gold row primary for PE/PEG/margins/ROE/etc.; Yahoo = fallback (`stocks.ts`).
- Fair value, score evidence, score history, trade overlay, event bullets, peer z = DB / nightly.
- `overlayBreakdownPrice` sets `metrics.currentPrice` from `getLivePrices` after cache — **but not** `dayChange` / `dayChangePercent` → list vs header % drift (Watchlist list uses live; header uses Yahoo-cached day%).

### Source map (optimal)

| Field class | Prefer | Yahoo role |
|---|---|---|
| Fund ratios / growth / quality / safety | `ticker_fundamentals` (merge-trusted) | Fallback only if gold null |
| Live last + day % | `getLivePrices` (Schwab→Yahoo) | Fallback inside live-quote only |
| FV / scores / overlay / bullets | Existing snapshots / DB | None |
| Analyst actions | DB when fresh (Yahoo write-through already); FMP analyst feed already merged | Live Yahoo only if stale |
| Earnings history | DB when fresh | Live FMP/Finnhub path already |
| Description / exchange / 52w / rec trend | Optional progressive | Yahoo OK deferred |
| News strip | Desk / book news if available; else Yahoo search | Convenience, not fund truth |

### Sibling surfaces (same issue)
1. **Breakdown** — worst: multi-module quoteSummary + search every cold miss (2h `breakdownCache`).
2. **`/stocks/quote` + `/stocks/quotes`** — `fetchQuoteMetrics` always Yahoo quoteSummary (Watchlist correctly avoided `/quotes`; other callers may still hit it).
3. **`/stocks/compare`** — two quoteSummaries.

### Out of scope
- Changing merge-trusted FIELD_DEFS or fund/option scores.
- Replacing gold with Yahoo, or Schwab fundamentals for trusted merge (playbook forbids).
- Lenis / LazyMount (A182) / chart history DB (A181).

### Acceptance
- Cold Breakdown returns usable fund + live price/day% **without** waiting on Yahoo quoteSummary (Yahoo may fill description/news/rec async or second phase).
- `dayChange` / `dayChangePercent` overlay from same `getLivePrices` entry as `currentPrice`.
- Quote + compare share the DB-first path (or documented why not).
- Before/after: p50 cold TTFB on a warm-DB ticker; fund numbers match gold; no score formula change.
- Claude plan review → `planned`.
