# A252: Rankings live-price fan-out per load (A64 pattern recurs) — default to DB-only
**From → to:** Muse → Cursor · **Date:** 2026-10-24 · **Status:** planned
**Source:** Muse code review 2026-10-24, finding H1 (High).

## Ask
Stop `GET /api/options/rankings` from fanning out live vendor quotes on every load. Make the DB-only path the default; live prices only on explicit refresh.

## Detail
Evidence: `artifacts/api-server/src/routes/options.ts` (pushed branch) does `const live = await getLivePrices(rows.map((r) => r.ticker))` unconditionally for every snapshot row. Same shape as the known A64 uncached-per-load query, now on the vendor-quote side (Schwab → Yahoo per ticker).
Note: the Mac working tree already carries a partial fix (`livePrices=0` query escape hatch that skips the fan-out). First check whether that change has landed on the branch; if not, port it — do not rewrite it a second way.
Fix direction: port/keep the `livePrices=0` escape hatch and flip the default so the board loads DB-only unless the caller opts into live prices (or a single batched quote call with a short TTL).

## Pass/fail
- Rankings board loads with zero vendor quote calls by default (verify by log/code path, not by assertion alone).
- Live prices still available on explicit refresh; no snapshot row content changes.
