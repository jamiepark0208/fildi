## 2nd-level analysis

The honest frame: none of these trade real money in fildi — the no-AI-trading rule stands, and the reel's "live trading engines that run it" is not a fildi job. What each could be:

- **RD-Agent is the interesting one.** Its job — find new signals on its own — is the missing piece of A327's learning loop (which grades and demotes rules but does not originate new ones). If it can originate a factor that survives out-of-sample on fildi data, it earns a research-lane job; if it only re-derives known factors, it is a duplicate of the loop's own search.
- **TradingAgents and AI Hedge Fund are the same bet twice:** multi-agent LLM debate over trades. Fildi already has OpenJev (local MLX, $0, registry-graded) and Haiku explains for the same job. The question is whether an LLM debate adds anything to the paper-trade/pundit layer — and both burn API tokens per debate, where OpenJev costs nothing. Head-to-head, same universe, same scoring (Brier / put-pnl), or drop.
- **Freqtrade is crypto-only and fildi has no crypto book.** Verdict is drop-with-reason unless Jamie ever approves a crypto lane (he has not). Do not spend build time on it.
- **Qlib's portfolio layer** is the only untested Qlib piece, but S141's FAIL is the prior — it gets a probe only if RD-Agent (which builds on Qlib) passes Step 1.

## Use cases (Claude: propose additional ones before running)

1. **Signal origination for the learning loop:** RD-Agent mines candidate factors from fildi OHLCV + options-informed fields; survivors enter A327's challenger pool.
2. **Debate-as-second-opinion:** TradingAgents / AI Hedge Fund paper-trade the scored book's names; their hit rate is graded against OpenJev's registry the same way pundits are graded.
3. **Paper-trade ledger:** AI Hedge Fund's hash-chained paper-trade ledger is a pattern worth stealing for the AI loop's own paper trades, even if the agents themselves are dropped.

- **Step 4 — Qlib portfolio layer:** probe only if Step 1 passes; else the S141 FAIL stands as the Qlib verdict.
