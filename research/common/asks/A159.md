## Detail
- **Question:** when price reaches a support/resistance zone, does the zone hold? Zones = volume-at-price nodes / POC per stock (TradingView-style volume profile) from `prices_historical` (split-adjusted; A16), 2 y daily.
- **Labels:** every touch (low within 0.25 ATR of the zone) → holds = close stays above zone − 0.5 ATR for the next 5 days. Features known at touch time only (touch count, recency, distance in ATR, prior reaction size, volume share). Time split: train first 70 % of dates, test last 30 %.
- **Models:** (1) touch-count rule (S040 baseline AUC 0.54), (2) logistic/small GBM on the zone table, (3) optional OpenJev zone-table text prompt + trained head (`scripts/oj.py`, P22).
- **Pass:** test AUC ≥ 0.60 for (2) or (3), beats (1) by ≥ 0.04, both halves of the test window. Fail → record in `research/studies/INDEX.md` and stop (no swing-low/S/R feature ships; setup.py unchanged).
- **Deliverables:** `scripts/watchlist_sync/analysis/s041_sr_v2.py`, `out/opt/S041.md`, INDEX row, registry row P22 via `oj.py eval` (numbers only from eval). Commit with `Refs: A159`.
