## Context
From @josholdmixon's reel ("Quant" — free strategy-validation tool). Verified 2026-10-16:
PentPort (pentport.com) is a real brokerage startup with a quant/data offering:
- **Options**: current chains + contract history (5,000 OHLCV/VWAP bars per contract)
  with Greeks (IV, delta, gamma, theta, vega), minute→monthly.
- **Prediction markets**: live YES/NO prices + full probability history.
- **Stocks/ETFs**: 1-minute bars, up to 5,000 bars/request.
- Papers library ("Explore Papers") for strategy research.
- Pricing: free tier exists; data API + backtests + quant build need Competitive
  ($9.99/mo or $99/yr). Account required — could not functionally test without signup.
- Notable: their example code uses `SIGNAL_DATE_MODE = "public_confirmation"` —
  they handle the A131 timestamp-leakage issue correctly.
