## What SkillOpt is (verified from repo)
- Treats the skill document as the **trainable state of a frozen agent**. Loop: rollout →
  reflect → aggregate → select → update → evaluate.
- A separate optimizer model proposes bounded add/delete/replace edits on one skill document;
  a candidate edit is accepted **only when it strictly improves a held-out validation score**.
- Deploys a compact `best_skill.md` (300–2,000 tokens), zero extra inference calls at runtime.
- Claims: best/tied-best on 52 (model, benchmark, harness) cells; +19–25pt lifts; skills
  transfer across model scales and harnesses. Integrations for Claude Code, Codex, Copilot, Devin.
- SkillOpt-Sleep: nightly offline self-evolution (harvest → mine → replay → consolidate behind
  a held-out gate) for recurring agents.
- Requirements: a **scored task with ground truth** (no validation score = no evolution) +
  optimizer-model API calls (cost; bound epochs, use cheap models).

## Why it fits fildi
Fildi's agents run on hand-crafted prompts/skills with no validation loop — exactly the setup
SkillOpt beats. The natural first targets are the **extraction agents**, because they have
measurable ground truth:
- A97 analyst-target parser: parse accuracy vs FMP target rows (authoritative target/firm/date
  in the newsTitle — free labeled set).
- A85 pundit view extractor: extraction precision/recall vs a hand-labeled call set.
- Headline classifier / sector-tagger: accuracy vs labeled headlines.

## What to build (phased)
- **Phase 1 — reproduce on one task**: run SkillOpt's loop on the A97 headline parser.
  Labeled set ~200 headlines (FMP rows as ground truth); optimizer proposes prompt edits;
  held-out validation gate mandatory. Baseline = current hand-crafted prompt.
- **Phase 2 — adopt on strict improvement**: deploy `best_skill.md` only if it beats the
  baseline on the held-out set. Cost tracked per epoch; cheap optimizer model.
- **Phase 3 — expand**: pundit view extractor (A85), then other agent skills. Evaluate
  SkillOpt-Sleep nightly evolution for the recurring research/brief agents.
- **Guardrails**: validation gate is non-negotiable — no unevaluated prompt change ships
  (same bar as the quant review gates). Evolved skills stay versioned; rollback on regression.

## Acceptance

- [ ] Adopt/reject decision made on held-out numbers, not vibes.
- [ ] Cost per evolution run recorded; bounded-epoch policy set.
