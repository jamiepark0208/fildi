## Context
Jamie asked about new agent use cases — grokbot, dots, instinct, hermes, openclaw —

## What each is (as observed Oct 15)

- **Hermes Agent (Nous Research, MIT, open-source)** — the interesting one. Self-improving
  architecture: after complex tasks it enters a "Reflective Phase," extracts reusable
  patterns, and writes a new skill file; three memory layers (session, episodic SQLite,
  procedural skills); 40+ bundled skills; model-agnostic (OpenRouter/Anthropic/OpenAI/
  local). Free (self-hosted). Directly comparable to A103's SkillOpt pilot — evaluate both
  and keep the winner for fildi's self-improving workflows.
- **OpenClaw (open-source)** — local-first personal agent on the user's own machine.
  Free (self-hosted). Evaluate as a local agent host for fildi automation (dev loop, DB
  audit) that must stay on his Mac.
- **GrokBot (xAI)** — persistent cloud agents, distributed via Cursor; reported at
  ~$20/mo via Cursor Pro after a price cut. Not free — note and move on unless pricing
  changes.
- **Dots (OpenAI)** — persistent agents inside ChatGPT, enterprise/high-tier oriented.
  Not free-tier — note and move on.
- **Instinct** — well-funded startup personal agent (text apps), waitlist/invite. Free
  tier unclear — check before any evaluation.
- **Meta Muse** — consumer personal agent with a genuine free tier. That's this
  conversation — no action.

## Evaluation questions
1. Which of these could host fildi's recurring agent workflows (dev loop, DB audit,
   repo watch) cheaper — in tokens and dollars — than the current cron setup?
2. Hermes vs SkillOpt (A103): which self-improvement loop actually compounds? Run both
   on the same pilot task (A97 analyst-target extraction) and compare.
3. Does any of them replace a paid piece of the current stack, or is this novelty?
   Default answer is "stay" unless the numbers say otherwise.
