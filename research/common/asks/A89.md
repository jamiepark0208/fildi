## Context
Jamie asked (Oct 14) about the "spawn many agents, kill the weak" Darwinism idea — is it ML, and
are there frameworks to copy? Answer: yes, it's ML — evolutionary algorithms (genetic algorithms,
evolution strategies, population-based training, NEAT) = derivative-free black-box optimization.
Web research completed Oct 15, including trading applications and failure modes.

## Research headline
- Trading applications exist: EXAMM-evolved RNNs beat DJI/S&P 500 in 2022–2023; GP trading rules
  (fitness = excess return); GA with Sharpe-ratio fitness; multi-objective profit-vs-drawdown with
  train/test gates. Laptop-scale compute is realistic (pop 30 × 15 gens ≈ 1h).
- **Critical lesson: raw-profit fitness overfits catastrophically.** One 500-agent system's 300%+
  validation APY decayed >70% on live capital. Failure modes: overfitting noise, survivor bias under
  high-variance selection, Goodhart on the fitness metric (one run degenerated to a single lucky
  trade), diversity loss, regime fragility.
- Requirements that make it work: risk-aware fitness (Sharpe/drawdown Pareto, never raw profit),
  small-tournament selection + elitism, train/test selection gate, walk-forward across regimes.
- **Verdict: evolve strategy parameters/rules OFFLINE with walk-forward validation — worth doing.
  Evolving live LLM agents on PnL is a fast path to Goodhart ruin** (PnL too noisy, LLM eval too
  expensive at population scale).

## What to build
1. **Variant spawner**: generate strategy-parameter variants (thresholds, weights, sizing fractions)
   from the existing scorer/strategy code — offline, on historical data only.
2. **Fitness**: Sharpe/drawdown Pareto rank + walk-forward validation across regimes; train/test
   gate before any variant is even shown to Jamie.
3. **Selection loop**: tournament selection + elitism over generations; hall-of-fame of past winners;
   diversity guard (kill only if a variant is dominated on all objectives).
4. **Promotion**: winning variants surface in the A88 review queue; Jamie approves before anything
   touches production. Never auto-promote.
