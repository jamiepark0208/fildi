It then runs cursor-agent with `FILDI_PARENT=<from>:<id>` in its env and appends `event:"dispatch-end"` with the exit code. `<from>` = claude when the wrapper runs under a Claude Code shell (the parent chain has `.claude/shell-snapshots`, same test as agents.ts `owner()`).
2. **Hook tag:** `.agents/hooks/agent-event.mjs` copies `FILDI_PARENT` into each event as `parent`, so the child's events tie back to the dispatch.
3. **API + UI:** agents.ts groups `dispatch` events (running until `dispatch-end`, or no child event for 10 min) → `dispatches: [{from, to, model, task, startedAt, running, actions}]`. Stage draws a beam from → to (same style as the OpenJev beam) with the task label, and shows the child under the target agent as "from Claude: <task>".
