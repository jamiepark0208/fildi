### Use cases (with why + expected value)
1. **GARCH+ML vol forecast per watchlist name (build if leg passes).** Next-month realized-vol forecast (GARCH(1,1) + gradient boosting on vol5/vol21/vol63 + GARCH, refit weekly) feeding put_edge's vol input and strike-width choice. Why: vol is the put-seller's raw material; a 3–5% MAE improvement compounds across every short put. Expected value: MAE improvement ≥3% over GARCH alone on SPY + 5 watchlist names out-of-sample; measured weekly.
2. **Pairs cointegration screen as a watchlist, never a signal (build as screen only).** Nightly Engle-Granger screen over the watchlist universe with pass-rate-vs-chance printed alongside every hit. Why: the repro proves hits at the 5% level are chance-level (1 found vs 3.9 expected) and break out of sample (+19.9σ). Expected value: a mean-reversion watchlist for the Breakdown panel with the base rate visible — and a standing rule that no pair becomes a trade signal without 2y out-of-sample survival.
3. **GMM regime cross-check for the shared regime service (build with A400).** Unsupervised 2-state GMM on the equal-weight watchlist index; report agreement/disagreement with the HMM filtered probability daily. Why: two independent regime estimators that agree are worth more than one; when they disagree, the guard stays conservative. Expected value: regime-service agreement rate + stress-day flag rate on holdout windows.
4. **PCA book-concentration view (build if leg passes).** PC1 share + per-name loadings across the open put book. Why: all 12 loadings same sign means the book has one factor, not twelve names — concentration risk the put-seller cannot see from tickers alone. Expected value: a concentration number per book snapshot; when PC1 share rises, position sizing tightens.
5. **RF direction test as a permanent negative control (build as eval, not as a model).** The exact RF setup re-run on fildi's own bars in the eval suite, with the always-up baseline and binomial p-value printed. Why: stops anyone re-litigating "just predict direction with ML" — the test is already run, the answer is already no (p = 0.28). Expected value: zero re-litigation; every future direction model must beat this control on the same split.
