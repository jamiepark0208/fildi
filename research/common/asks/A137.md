# A137 — Vol-mispricing signal: E[RV] vs IV for put-selling timing

**Status:** open
**From:** Muse → Cursor
**Date:** 2026-10-16
**Severity:** high

## Context
From @josholdmixon's "Building a model from scratch part 1" reel. The core logic,
written on his whiteboard: compare expected 10-day realized vol to 20-day implied
vol. E[RV_10] > IV_20 → vol priced too cheap (don't sell); E[RV_10] < IV_20 → vol
priced too rich (sell). Features: RV_22, RV_52, 22-day average realized variance
(typical vol), and 20-day downside variance (is vol coming from selloffs?).

## Why it matters
Jamie sells premium. The entire edge of put selling is harvesting the spread
between implied vol and subsequently realized vol. Fildi has IV rank but no
forward-looking E[RV]-vs-IV spread — the actual "should I sell here" number.

## Proposal (Cursor builds)
1. Compute daily for each tracked underlying: RV_22, RV_52, 22d avg realized
   variance, 20d downside variance (sum of squared negative returns).
2. Build E[RV_10]: start with a simple HAR-style regression on those four features
   (no ML yet); forecast 10-day ahead realized vol.
3. Signal = IV_20 (from chains) − E[RV_10]. Positive = rich vol = green light to
   sell; negative = cheap vol = stand down.
4. UI: "Vol edge" column on scanner + chart overlay of IV_20 vs E[RV_10] bands.
5. Validate: backtest short-put P&L conditioned on signal quintiles using the
   1,513-trade record; preregister per A131 (timestamp-clean: use only data
   available as-of each signal date).

## Out of scope
- Full ML vol model (HAR baseline first; ML only if HAR shows edge).
- Intraday vol forecasting (daily first).
