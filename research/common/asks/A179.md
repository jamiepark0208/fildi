## Detail

### Benchmark (tool-agnostic daily put-seller)
1. Regime check (VIX level, rates/credit, calendar) → size / skip.
2. Shortlist names you’d want assigned to (intent tags are personal notes, not scores).
3. Premium hunt among candidates (IV, buffer, DTE, ER distance) — scores independent of tags.
4. Name diligence (fund + chart + event risk).
5. Book & size (real book vs practice book stay separate).
6. Intraday manage; weekly calibrate.

### Product facts (Jamie 10-18 / 10-19 — do not violate)
- **Portfolio (admin)** = Robinhood real book. Keep it.
- **Live › Portfolio Alerts** = practice / e-book risk for non-admin users (admin still uses both). **Do not unify** these books.
- **Color tags** = personal intent on Watchlist only. **Must not** filter or re-score Options Rankings. Tags can be wrong; option scores stay independent.
- **Fundamentals Rankings** = market-wide fund review for everyone. **Do not demote** for a CSP path; not options-shaped by design.

### In scope (build after Claude plan review)
1. **Today / desk landing** (or Live default strip) — regime one-liner + as-of + calendar hint + top Options GO from the **universe scorer** (not tag-filtered) + optional Alerts stress for practice book. Discovery only; no score changes.
2. **Open Options → ticker-scoped** — from Watchlist/Breakdown name card, open that ticker’s chain / prefiltered Options row, not the global board.
3. **Trust chrome** — loud as-of stamps on Options/Live quotes; suppress or flag absurd day-% (e.g. VIX −45% off-hours); one labeled win-rate definition where summary vs tilt disagree. Display/trust only.

### Out of scope
- Unifying Portfolio ↔ Portfolio Alerts.
- Color-tag filters on Options or Fundamentals rankings.
- Changing option or fundamental score formulas for workflow UX.
- Parked ASKS / Ideas build spree beyond these three.

### Suggested user workflow (docs / Today copy once UI lands)
Macro strip → (RH Portfolio when sizing real capital | Live Alerts for practice risk) → Rankings Options on its own merits → name card diligence → Track Record edge check. Watchlist tags organize attention only.
