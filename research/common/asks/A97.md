2. **Widen the firm|date pairing** (`stocks.ts:872-888`): ±3-day window + firm-name normalization

   FMP numbers.
3. **Headline parser as-is** — already live on Yahoo news titles, already fills some cells, correctly
   badged "News-derived". No change needed; coverage grows with news flow.
4. **One-time LLM pass** over archived fmp-target titles the regex can't parse (odd phrasing,
   "lifts objective", byline formats). Cheap, offline, fills route 1's residue.
5. Finnhub `/stock/price-target` — skip; redundant with the FMP feed already paid for.
6. **Email pipeline** (Jamie-flagged 2026-10-14): `desk_commentaries` stores full `body_plain` +
   `tickers_mentioned` from Gmail→Drive ingest (FactSet/StreetAccount, Axios, Bloomberg, TipRanks
   watchlist digests, ZeroHedge, …). TipRanks digests already carry analyst/PT activity in regular
   format. Run `analyst-headline-parser.ts` over subjects/bodies → `analyst_events` with
   `source:'email'`; or a TipRanks-specific extractor for highest precision. Caveat: desk email is
   soft-context-only today — first scored use needs the same "news-derived" confidence treatment.
