1. **Client `scripts/lse_client.py`** (Python, reuse `build_plan.connect` for DB): key from `.env.local`; 20 s deadline per call; token bucket 55/min; on 429 sleep `Retry-After` then retry once; every call upserts `api_usage` (source `lse`, +1); JSON answers saved whole to `vendor_raw` (source `lse`, endpoint, key = symbol|from|to); CSV exports parsed into the target table (vendor_raw stores the CSV text in `payload->'csv'` only for ≤ 200 KB files).
2. **Catalog/metering:** `lib/data-sources-catalog.ts` row (`id: "lse", usageKey: "lse"`, name "London Strategic Edge", limits above, what we take); `lib/api-logger.ts` source union + `ApiMonitorTab.tsx` entry (limitKind per-minute 60); `research/common/external-tools-audit.md` LSE row → "wired A357"; `research/common/data-inventory.md` row.
3. **Backfill `scripts/watchlist_sync/analysis/a357_lse_option_backfill.py`:** contracts = the put rows of `s059_option_factors.trades()` (the same set `a352_score_rank.py` grades) with entry ≥ 2025-10-15, plus every `public.model_recs` put. For each contract → `GET /v3/export?market=us_options&symbol=<OCC>&timeframe=1d&from=<entry−3d>&to=<expiry>&format=csv` → table `lse_option_daily(occ, ticker, side, strike, expiry, date, open, high, low, close, volume, fetched_at, PK(occ,date))`. Store "no trades" (404 data-unavailable) as a row in `lse_option_fetch_log(occ, status, fetched_at)` so reruns skip it. Resumable; `--limit N`; `--dry-run` prints the contract count. **Smoke first: 20 contracts, check 3 by hand vs `option_chain_history` closes where dates overlap (10-08+).** Then full run in the background (~3–4 h for ~12k contracts at 55/min; never in parallel with another LSE job).
4. **Re-grade (`a357_regrade.py`, writes `research/studies/a357-real-price-regrade.md`, INDEX row):** on weeks ≥ 2025-10-20 only. Entry price = traded close on entry day (±1 trading day); exit = settlement intrinsic at expiry (as A352). Report, best cell first:
   - coverage: % of contracts with an entry trade, **by score tercile and delta bucket** (selection-bias check: if T1 covers ≥ 10 pp more than T3, say so and grade only on common weeks/names);
   - modelled vs traded entry premium: median ratio + IQR by delta bucket and DTE;
   - champion top tercile vs random same-delta vs T-bill, bp of strike/week, on traded prices with 0 %, 5 %, 10 % haircut (trade close ≈ mid; Fildi sells at bid, RH fill = bid + ~23 % of spread), and the same weeks on modelled prices side by side;
   - mirror side (buyer of the same puts) — per PLAYBOOK 4b.
**Pass/fail (pre-registered):** coverage ≥ 60 % of contracts. Edge **holds** if top-tercile minus random same-delta on traded prices at 5 % haircut has the same sign as modelled and ≥ half its size on the same weeks; **weakens** if same sign < half; **fails** if sign flips. 56 weeks ≈ N_eff small → report N_eff (REVIEW 6) and say "underpowered" rather than FAIL if CI spans 0.
**Acceptance:** `/v3/usage` shows calls used; `api_usage` has `lse` rows; tests for OCC formatting (root padding, strike ×1000, 8 digits) + resume skip; no secrets in logs/packet. Packet ≤ 20 lines under ## Reviews as "Cursor packet <sha>".
