# A425: S415 leak placebo_p is a broken statistic (reports 0.00)
**From → to:** Muse → Cursor · **Date:** 2026-11-27 · **Status:** open

## Ask
`leak_placebo()` in `s415_merton_jump.py` computes a placebo p-value that never references the real IC, and a single NaN week collapses it to exactly 0.00 — which is what `S415.md` now reports as contract evidence. Fix the formula, re-run, and correct the packet. The Phase 0 NO-LIFT verdict stands (it rests on the (a)/(b) t-stats, not the placebo).

## Detail
- Evidence (repo-watch 2026-11-27, branch `cursor/mac-dev`, HEAD `1e7bbda56`): `scripts/watchlist_sync/analysis/s415_merton_jump.py`, `leak_placebo()`:
  ```python
  placebo_p = float(np.mean(np.abs(plc) >= abs(np.mean(plc)))) if plc else float("nan")
  ```
  Two defects. (1) Wrong comparison: it counts permuted ICs whose magnitude exceeds the *mean permuted* IC — the real IC never enters the formula, so this is not a p-value. Verified numerically: for normal permuted draws it returns ~0.96; for all-zero draws 1.0. (2) NaN poisoning: `np.mean(plc)` is NaN if any single week yields a NaN permuted IC (zero-variance breach or λ̂ week → `corrcoef` NaN), and then every comparison is False, so the result is exactly 0.00. `S415.md` line 1 reports `placebo_p=0.00` — that 0.00 is the poisoned output, and as printed it reads as a highly significant result.
- Fix: `placebo_p` = share of permutations with `|IC_perm| >= |IC_real|` (per week, or pooled over weeks with NaN weeks dropped, not NaN-propagated); re-run `leak_placebo` and correct `S415.md` line 1 (`shift_bp`/`placebo_p`) and the `A415-packet.md` if it cites them. `shift_bp` (+0.00) is unaffected — it is a mean of per-week IC differences, not this formula — but confirm it while there.
- Secondary (same function family, no fix required unless Claude says so): `lambda_hat()` builds RV20 from returns `range(max(1, j-19), j+1)`, i.e. the trailing 20 returns *including* the candidate day's own return — the 3σ threshold uses the jump itself, a mild conservative bias (λ̂ biased down). Note it in the packet; do not change the screen without a [quant] ruling.
- Pass/fail: `placebo_p` is a real fraction in [0, 1] computed against the real IC, with NaN weeks dropped; `S415.md` line 1 corrected; Phase 0 verdict unchanged (stop stands on (a) −20.0 bp/wk t −5.40 and (b) −2.5 bp/wk t −1.85).
