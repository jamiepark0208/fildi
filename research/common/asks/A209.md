# A209: Agent learn feed — turn metrics + shared optimization loop
**From → to:** Jamie → Cursor · **Date:** 2026-10-20 · **Status:** done (P0; P1–P3 open)
**Moves:** ops

## Context
Jamie wants AI › Stage / Activity / Usage to quantify agent work so Cursor, Claude, Codex, Muse, Grok can continuously cut token waste and improve workflows — same numbers, same feed, not vibes. Activity is already one row per prompt; next step is measurable cost + outcome per turn and a machine-readable API every agent reads at session start.

## Ask
Ship a shared **learn** surface: persist prompt-turn summaries (cost + behavior), join outcomes where cheap (`Refs: A##`, ship_ok, fails, loops), expose `GET /api/agents/learn`, and show efficiency columns on Stage + Usage. No new orchestrator. No portfolio/secrets in the learn log.

## Detail

### Unit of learning
One **turn** = events from `prompt` → next `prompt` (or stop) within `(agent, session)`. Tools stay nested under the turn (A209 UI already started in Activity expand).

### Schema (turn summary — write at `stop` / periodic flush)
```json
{
  "id": "cursor-2026-10-20T16:06:30Z",
  "agent": "cursor",
  "session": "…",
  "t0": "ISO", "t1": "ISO", "wall_s": 120,
  "prompt": "≤120 chars",
  "ask_id": "A209|null",
  "in_tok": null, "out_tok": null, "cache_read": null,
  "tools": 14, "reads": 6, "writes": 3, "bash": 2, "mcp": 1, "edits": 3, "oj_asks": 0,
  "unique_files": 4, "reread_same": 2,
  "loop_hits": 0, "fails": 0,
  "ship_checks": 1, "ship_ok": true|null,
  "commits": 0, "outcome": "ok|fail|review|unknown"
}
```
- Tokens: Claude from existing session logs when joinable; Cursor/Codex null until Usage API / host meter (show `unknown`, never invent).
- `ask_id`: parse `Refs: A##` from prompt text or later commit trailer in the same session window.
- Persist: `~/.fildi/agent-turns.jsonl` (append-only, 7–14d retention trim).

### API
- `GET /api/agents/learn?since=ISO&agent=` → `{ turns[], rollups24h[], wasteTop[] }`
- Rollups per agent: `tok`, `acts_per_commit`, `loop_pct`, `fail_pct`, `oj_asks`, `ship_ok_rate`, `rework` (review findings when linked).
- Admin-only (same as overview). No prompt bodies beyond 120-char already stored; no tool stdout.

### UI (AI tab)
1. **Agent table** — add: Tok (24h) · Acts/cmt · Loop% · Fail% · OJ (keep Errors, Avail, Queue, Commits).
2. **Activity turn row** — add: Tok · Wall · R:W · Loop · A## · Outcome (expand still shows tools).
3. **Usage** — “Waste leaders”: top turns by tools or tok with `commits=0` / `ship_ok=false`.
4. **Skills** (phase 2): `uses7d` + hit rate when turn used skill path → ship_ok / oj_outcome.

### Shared agent ritual (docs only in phase 1)
Document in `AGENTS.md` / adapters: session start → `GET /api/agents/learn?agent=<me>` → note top 3 waste turns → prefer oj/codegraph when Acts/cmt or reread_same high. Mirror OpenJev: measure → other agent can verify → demote bad habits via rules/skills edits with evidence.
