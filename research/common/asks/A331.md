## Design (copied from proven tools)
- **TradingView Strategy Tester:** Overview / Performance / List of trades tabs, trades drawn on the chart.
- **Freqtrade FreqUI backtesting:** pick strategy + timerange, run, per-pair results, trades on the chart.
- **backtesting.py / QuantConnect reports:** equity curve, monthly heatmap, trade list linked to the OHLC chart with indicator panes.

### Left panel: inputs (everything Claude sets when it runs a study)
1. **Universe:** tickers, sector, or all; filer type; min price/volume.
2. **Dates:** start, end; fit / check / holdout split dates. The holdout stays locked until "Unlock holdout" is pressed; the unlock is logged per run.
3. **Signal builder:** a preset, or up to 3 conditions joined by AND.
   - **Presets** from INDEX: S151 put_climax_spy_oversold, put_climax_low_ivrv, sell-call context, S059 put-edge Q5, S102 sector-drop, S147 features.
   - **Each condition:** feature (catalog: RSI2/14, z5, stochastic, BB %b, up/down climax, volume z, IV÷RV, IV rank, ATR pct, pivots/S-R distance, MA50/200 distance, 15/30-day return vs SPY/sector, SPY RSI/MA distance, breadth, skew, GEX), test (quintile N computed on the fit window, or value > / < x), lookback.
   - **Label horizon** (next day / week / month / quarter / intraday) for the lift view.
4. **Trade:** instrument (sell put/call, long call/put, stock), delta or % OTM, DTE range, entry (signal close / next open / 5-m VWAP reclaim), exit (expiry / take-profit % / stop % / ½-DTE / signal flip), fill model (bid + x % of spread), cost stress %, pricing (Black-Scholes at IV × skew, or real quotes where stored, with a coverage %).
5. **Comparator:** any day, same sector-month, or a saved run.
6. **Run:** shows the estimated size (name-days, trades). Results cache by parameter hash.

### Right panel: results
- **Summary cards (signal vs base, per period: fit / check / 2018–22 / holdout):** n trades, n months, win %, mean and median P&L per $, breach %, worst 5 %, excess vs base, month-block t, a ±cost-stress line. Verdict chip against the pre-registered bar: the sell bar or the strict long bar.
- **Equity curve:** signal vs base, with drawdown.
- **Monthly P&L heatmap.**
- **Lift table:** each condition by quintile → P(good low/high) ÷ base, per half.
- **Trades list:** date, ticker, entry, strike, premium, exit date and reason, P&L, breach. Click a trade → chart.
- **Chart (reuse `price-chart.tsx`):**
  - candles + volume;
  - markers: signal day ▲, entry, exit;
  - strike as a price line;
  - indicator panes for the run's conditions (RSI, volume z, IV÷RV …) with the quintile cut-offs drawn as lines.
- **Point-in-time inspector:** click any bar → every catalog feature's value, its quintile on that date, whether each condition fired, the label outcome (did the week low hold, max drop/rise in ATR), and the trade that would have opened. This shows Jamie what Claude sees.
- **Saved runs:** name, compare two side by side, "Send to shadow" (creates an A327/A330 challenger; never goes live directly).

### Guard against overfitting (the UI makes tweaking easy)
- A session counter of runs tried.
- A multiple-testing note: BH-adjusted p across the runs in the session.
- Holdout locked by default.
- A result that passes only after many tweaks is labelled "searched — confirm on holdout once".

### Backend (one producer, runtime-safe per rule 8c)
- **Python runner** reusing `pattern_lab.py` features, `s151_phase4_excess.py` trades/baseline and the S081 pricing. No new engine.
- **Feature cache:** daily parquet by date. Run deadline 120 s, one job at a time (queue), cached by hash.
- **Endpoints:**
  - POST `/api/backtest/run` → run id;
  - GET `/api/backtest/runs[/:id[/trades]]`;
  - GET `/api/backtest/catalog` (features with a one-line description, source study, presets);
  - GET `/api/backtest/inspect?ticker&date`.
- **Stored data only ($0 vendor):** `lseg_research.daily_history` 2016→, `optlab.bars_5m` 2024-10→, `optlab.bars` / `option_chain_history` for real quotes.
- **Table** `backtest_runs` (params jsonb, hash, summary jsonb, created_by, holdout_unlocked).
