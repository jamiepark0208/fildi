## 3. First- and second-level analysis

First level: this is two separable pieces, not one stack. OpenBB is a data
platform (valuable if its free providers cover fildi gaps); Hermes is an agent
harness (valuable only if its reports beat fildi's existing Haiku explains
and its memory loop is graded, not vibed). The reel fuses them into one
"terminal" story; the plan must judge each piece on its own verdict, or a
weak half rides in on the strong half.

Second level: what fildi actually lacks that OpenBB could fill is narrow and
concrete — SEC full-text/statements as a research cross-check (A318's EDGAR
TTM period check is exactly this shape), Cboe delayed options as a second
history leg where optlab is thin (A319 UC1 adjacent), and macro (FRED/IMF/ECB)
for regime context (A314). What fildi does NOT need is another live data
vendor: Schwab/Yahoo already own live chains and bars, and no OpenBB output
enters a live score until it passes the golden-source bar below. Hermes'
"self-improves with every decision" is the claim fildi's own learning
framework refuses to take on faith (survey Nov 3: measurement good, retune
poor, Step 6 unbuilt) — so Hermes memory is research-only, human in the
middle, never an auto-retune of live rules. Roster note: Hermes would be a
fourth agent voice alongside Muse/Claude/Cursor; whether Jamie wants that is
his decision, flagged in step 6, not buried in the build.

## 4. Use cases (why + expected value)

- UC1 — SEC research cross-check for gold fundamentals. Why: fildi's gold
  picker (A318) already wants EDGAR TTM as a period check, and EDGAR full-text
  has zero code refs today. OpenBB-sec gives filings, statements, and full-text
  search keyless. Expected value: a second, free source for the exact fields
  where vendor disagreement is worst (operating margin, EPS), cutting FactSet
  referee calls on the 40-name morning job.
- UC2 — Cboe delayed options as a second history leg. Why: fildi's option
  history is LSEG optlab (~1.3 strikes/name/date) + Schwab-forward; thin
  history starves put-pnl harness studies. Expected value: one more history
  source for backtest studies (research only), judged against optlab/Schwab
  on overlapping series.
- UC3 — OpenBB MCP as an agent research tool. Why: a typed, tool-shaped data
  surface beats ad-hoc scraping for research agents. Expected value: Muse /
  Cursor research queries (filings, macro, delayed quotes) run through one
  MCP server instead of N bespoke fetchers — but only if the tool list is
  enumerated and each tool's provider + delay + key requirement is documented.
- UC4 — Hermes report pilot vs Haiku explains. Why: the reel's "report like a
  financial analyst" is fildi's R1 (survey Nov 3: "why this folder, why this
  rank" prose) in another harness. Expected value: adopt Hermes reports only
  if a graded pilot beats Haiku explains on accuracy with zero invented
  numbers; otherwise drop Hermes and keep Haiku. Never a live-score input.
