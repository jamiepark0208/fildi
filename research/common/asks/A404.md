## 1st-level analysis

Cursor expires Dec 11, 2026 and Jamie will not renew. The post-Cursor picture is model (GLM) + harness (OpenCode) + DeepSeek (A351) + Qwen local — four candidates, one seat each. A361's bake-off priced OpenCode's routes as Zen Go $10/$40 mo or BYO API key. The subscription provider changes the cost leg entirely: Claude Pro is already paid, so a working subscription route makes OpenCode's Claude route $0 marginal — cheaper than every other route in the bake-off, on the strongest model family (Claude Opus 5.5 / Fable 5.2 tie Terminal-Bench 4.1 at 65.8%, read Nov 13). But a route that Anthropic can switch off without notice is not a seat — it is a loan. The test must answer two questions in order: (1) does it work on the Mac with Jamie's login, and (2) is the permission real. A "works, permission unclear" result is a drop for the seat, not an adopt.

## 2nd-level analysis

The failure mode to avoid is the one that bit the Jan 2026 ban: building the whole post-Cursor workflow on a subscription route, then losing it mid-build with no fallback. So this row is scoped as a route test inside A361's bake-off, not a second bake-off: same fixed A351 build task, same grading bar, plus a permission verdict. If the route works AND permission is confirmed in writing, A361's P3 cost bar is met by definition and the subscription route becomes the default OpenCode route. If it works but permission stays unconfirmed, the route is recorded as at-risk with a named fallback (Zen Go or API key) and the seat decision stays with A361's other routes. If Anthropic confirms it is not permitted, the subscription route drops and A361 proceeds without it. Either way the Dec 11 decision gets a firmer answer than "Anthropic hasn't said anything."

Why: a seat built on an unconfirmed permission fails exactly when it is needed most.
3. **Model-route comparability.** Same fixed A351 task as A351/A361, so the subscription route's build quality is directly comparable to DeepSeek's harness and the GLM route. Why: cost without quality is not a verdict — the route must also build as well as the alternatives.
