## 1st-level analysis (Muse)

**Verified (Nov 6):** `deepseek-ai/deepseek-harness`, **274,346 stars, MIT, pushed Nov 4 2026** — the poster's "270K stars" checks out. "Everything is a Plugin." The carousel's two pieces:

- **Super-Agent:** an event-triggered coding agent. It wakes on events, not prompts — chat messages, emails, CI results, reviews ("Triggers"). One router talks to people and hands out work; each worker gets a single task and its own clean context. Brain in the cloud, a tiny daemon on your machine — it keeps working when the laptop goes to sleep. A bug report lands in the team chat, the agent reproduces it, writes the fix, opens the PR, nobody @-mentioned it.
- **Creator Mode:** one sentence → a working plugin/app (sticky-note wall, voxel game, video editor, 3D travel guide). Toys for fildi's purposes — not the evaluation target.

**Why this is the first serious candidate for the December seat:** Cursor expires Dec 11 and no replacement is decided. Harness is free + MIT, and its shape fixes two fildi problems at once: (1) the builder seat itself, and (2) the sleeping-Mac problem — fildi's scheduled tasks don't run while the MacBook lid is closed, and a cloud-brain + local-daemon agent keeps working through that. Event-triggered (not prompt-triggered) also maps to the repo-watch / agent-coordination loop Muse runs today.

**Honest caveats:** "Killed Claude Code" is hype — Harness runs DeepSeek models, not Claude, and quality on a TypeScript monorepo is unproven. The carousel's speed test (typical 12.4 vs 20.4 min; slowest 15.7 vs 29.5 min) is DeepSeek's own synthetic workload, ~20 requests, 5 runs, self-described "indicative only" — a pilot signal, not evidence. "Free" means the harness is free; inference is DeepSeek API-priced, not $0 — Step 3 prices it.

## 2nd-level analysis

The test that matters is not "does it install" but "does it build fildi code to the bar Cursor is held to." A build that passes the code-checked review (real verification, fixtures through their own math, downstream impact named) is the only pass that counts — a demo plugin proves nothing. The second test is the always-on loop: a trigger (CI result, chat message) firing a real fix while the Mac sleeps. If either fails, the seat stays open and the Qwen path (decision pending since Oct 31) is the remaining candidate. If both pass, the seat is filled before Dec 11 with a month to spare.

## Use cases (Claude: propose additional ones before running)

1. **Post-Cursor builder seat:** Super-Agent builds filed plans (low-risk rows first), graded with the same review bar as Cursor commits.
2. **Always-on repo watch:** event-triggered fixes — a CI red or a review comment fires a fix attempt without anyone prompting.
3. **Overnight queue work:** the cloud brain works the ASKS queue while the Mac sleeps, with results waiting in the repo in the morning.

## Plan

- **Step 0 — Mac install:** install Harness on the Mac, point Super-Agent at a fildi test repo (a copy, not the live tree, for the first run). Record version, the DeepSeek key setup, and what the daemon can touch.
- **Step 1 — Real build test:** Super-Agent builds one filed low-risk plan end to end. Grade the diff with the code-checked review bar. **Pass bar: the build passes the same review bar a Cursor commit must pass (tests, downstream impact, no regressions).** A demo plugin does not count.
- **Step 2 — Always-on loop test:** fire a trigger (CI result or chat message) with the Mac lid closed / asleep and verify the agent picks it up and lands a fix in the repo. **Pass bar: the event loop fires without a prompt and the fix lands.**
- **Step 3 — Cost:** price a month of DeepSeek inference at the observed usage vs Claude Pro $20/mo and the Cursor seat it replaces. "Free" is not the claim — the number is.
- **Step 4 — Verdict:** adopt as the post-Cursor builder seat, drop, or keep as a second builder — with a Settings catalog row either way (Jamie's Nov 2 rule).
