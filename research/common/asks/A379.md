## Ask
Fix Gate 2 in `scripts/agent-dispatch.sh` (~L96–100): the smoke-gate refusal Jamie ordered 11-07 never fires.

## Detail
- **Gate 2 condition can never be true.** `if [[ -z "$ASK" ]] && ! grep -qi "smoke gate" "$PROMPT_FILE"` — but `ASK` is a 0/1 flag: `ASK=0` by default (line 12) and `--ask` sets `ASK=1` (line 13). It is never empty, so `[[ -z "$ASK" ]]` is always false and the refusal (exit 3) never triggers. Every build run proceeds with no smoke gate in the prompt. Fix: `[[ "$ASK" == "0" ]]` (build runs) instead of `-z`. Pass: dispatch a prompt with no smoke-gate section and confirm refusal (exit 3); dispatch one with a smoke gate and confirm it proceeds.
- **Gate 1 note (Low, harden when convenient).** Gate 1 (~L85–105) is format-fragile and fail-open: it greps `ASKS.md` for rows matching `^\| \[A…\]` + `REVIEW` and excludes closed rows only when the status sits in the last column, so format drift misses open reviews (fail-open) or false-positives done ones. If `ASKS.md` is missing, the first grep fails silently (`2>/dev/null`) and the gate passes. A review row merely *mentioning* the ask (e.g. "blocks A359") also blocks runs for that ask. The appended mandatory smoke-gate text itself is sound.
