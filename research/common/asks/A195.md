# A195: [quant] Study — cointegration divergence as a put-selling entry signal

**From → to:** Muse → Claude · **Date:** 2026-10-19 · **Status:** open
**Source:** Reel by @josholdmixon (Jamie sent 10-20): pair trading explainer — cointegration ≠ correlation; enter on divergence, profit on mean reversion. His "nearly half of hedge funds" claim is unverified framing; the method is standard stat-arb.

## Thesis
Jamie sells puts directionally. The fildi-native version of pair trading is not equity pairs (needs borrow, two-sided infra) — it's **cointegration as an entry filter**: when a name in a cointegrated pair diverges DOWN vs its partner, its IV typically spikes and the spread historically reverts. Selling puts on the diverged leg = mean-reversion trade + premium.

## First-level analysis (Muse)
- Universe = A148 peer groups. Rough pair count: intra-group pairs plausibly 100–200 (Packaged Goods 7 names = 21 pairs; Regional Banks, Large Pharma, Semis add dozens). After Engle-Granger at p<0.05 with multiple-testing discipline, expect ~10–30 surviving pairs. **Power gate: if <10 pairs survive, kill as underpowered before any outcome testing.**
- Signal: spread z ≤ −2 on one leg, spread half-life 5–60d.
- Joint signal (stronger prior): divergence AND the cheap leg's IV rank >50 — divergence alone may just be cheap; divergence + rich IV is the put-seller's version.
- Harness: S003 reconstructed puts; signal-day entries vs all-day baseline, same names/eras. Metrics: premium kept %, assignment rate, worst-decile 5d underlying move, expiry ITM clustering (S015 check).
- Pass: premium-kept +≥10% relative with no worse tail. Fail either → kill the entry-filter use case (other use cases below are evaluated separately).

## Second-level analysis (Muse)
- **Adverse selection:** the cheap leg is often cheap for a reason. Split signal days by whether an earnings print or guide event sits within ±5 days (news-driven divergence) vs none (technical). If the edge lives only in news-driven names, it's a trap, not a signal.
- **Clustering:** divergences cluster in sector stress — all pairs blow out together, exactly when assignment risk is systematic. Report signal-day clustering (max signals in any 5d window) and cap interpretation accordingly.
- **Peer-group vintage:** A148 membership changes via the monthly control (A200). Pair universe must be versioned by vintage; results reported per vintage, never pooled across membership changes silently.

## Upstream data — dependencies & maintenance
- Daily bars: Schwab/Yahoo merged series (A63 source ordering matters — a stale stored Yahoo bar corrupts the spread). **Corporate actions are the #1 data risk:** an unadjusted split/dividend creates a fake divergence. Pre-study audit: verify adjustment consistency on every pair that produces a signal; any pair with a corporate action inside a signal window is excluded or hand-checked.
- New maintenance if adopted: a daily pair-state job (spreads + z-scores for surviving pairs — trivial compute), plus pair re-screening on each peer-group vintage change.

## Downstream impact
- If pass: scanner/Breakdown flag "diverged vs pair (z, IV rank)" — display only, no auto-trade (R9).
- If the entry filter fails: pair-spread state still feeds **A200 peer-drift monitor** — pairs drifting apart persistently = taxonomy decay evidence. The study's data work is not wasted either way.
- Morning brief: a "diverged vs pair + IV rich" shortlist is a candidate brief line (premium-rich mean-reversion candidates) — only if the study passes.

## Use cases (Muse, tested logic — in priority order)
1. **Put-entry filter** (core, above). Why: converts a stat-arb textbook idea into Jamie's actual payoff shape; expected value = premium-kept uplift on ~5–15% of entries that are pair-signal days.
2. **Assignment-risk early warning on HELD positions.** If a held short put's underlying keeps diverging DOWN vs its pair (spread widening against us), the dip is idiosyncratic, not market noise — a roll/close review trigger. **This use case survives even if #1 fails**: it needs spread state, not entry alpha. Test inside the same study: on held-position-like entries, did continued divergence at day 5 predict worse outcomes? Pass for this use case: day-5 spread widening predicts ≥25% worse premium-kept vs non-widening entries — then it ships as a warning flag regardless of use case 1.
3. **Peer-relative dislocation shortlist** for manual review (brief/scanner display). No alpha claim — a triage tool that surfaces the 2–3 most dislocated watchlist names each morning instead of Jamie scanning everything.
