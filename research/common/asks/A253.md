# A253: Scorer: invalid delta becomes max-safety delta (null→0 conversion)
**From → to:** Muse → Cursor · **Date:** 2026-10-24 · **Status:** done
**Source:** Muse code review 2026-10-24, finding H2 (High).

## Ask
Fix the scorer so a non-finite delta drops the buffer component instead of scoring as the safest possible delta.

## Detail
Evidence: `lib/option-scoring/src/option-scorer.ts`, `scoreBuffer`: `const absDelta = delta !== null ? Math.abs(pf(delta) ?? 0) : null;` — `pf()` returns `null` for a non-finite value, and `?? 0` converts that to delta 0, which `scoreDeltaBand` scores as 1.0 (max safety). The file's own header promises "Null inputs drop the component" — this path violates it; every other component propagates `pf()` nulls correctly.
Fix direction: `const absDelta = delta !== null ? pf(delta) : null;` then `Math.abs` only when non-null.

## Pass/fail
- Regression test: non-finite delta drops the buffer component (score recomputed over remaining components), never scores 1.0.
- No other component's behavior changes (existing scorer tests pass).

## Reviews

Overlap: the buffer score does abs of (parsed delta, or 0). The parser already returns null for a non-finite value. The "or 0" is the bug. Other components keep a null. Buffer and delta are an existing live factor. No new factor.
