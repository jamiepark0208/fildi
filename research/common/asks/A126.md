## Context
Jamie shared @fibsandflow's reel (order-flow charting: volume profile, bid/ask delta,
VWAP bands, EMA, DOM) and wants "indicators like this" on fildi's stock breakdown
charts, plus general chart UI improvement.

## What the charts have today (verified 2026-10-16)
- `price-chart.tsx` (lightweight-charts): candles, EMA 50/200 overlays, S/R zones
  (static + dashed MA/Bollinger), markers, price lines.
- Backend `indicators.ts`: RSI, MFI, ATR, MACD cross, Stochastic — computed but shown
  as numbers, not chart overlays.
- **Missing entirely:** volume histogram, volume profile, VWAP, delta/footprint, DOM.

## Data solution (revised per Jamie 2026-10-16: don't give up, find the way)
The reel's tools are order-flow: they want intraday data. Fildi's Schwab client
currently pulls only daily `/pricehistory` — but the same endpoint serves intraday
(`periodType: day/month` + `frequencyType: minute`, 1/5/15/30m). Same auth scope,
no new entitlement. So the plan ADDS a Schwab intraday pipeline instead of
settling for daily-only approximations:
- **Session VWAP**: proper per-session VWAP from 1m bars (the real thing).
- **Volume profile**: proper intraday-based POC/VAH/VAL.
- **Delta estimation**: true tick delta needs tick data (not available), so estimate
  per-bar buy/sell volume with the tick rule / Lee-Ready algorithm on 1m bars
  (academic standard, ~85-93% classification accuracy). Label it "estimated delta"
  in the UI — honest, not fake.
- **DOM/tape**: needs streaming Level 1 — out of scope for now (phase 2 via Schwab
  streaming API if ever wanted).
- Fallbacks: Schwab token fragility (A73) applies — Yahoo 1m bars (7d window) as
  fallback source; rolling 30-60d intraday retention so storage stays bounded.

## Proposal (Cursor builds)
**Phase 1 — intraday pipeline**
1. Extend `schwab-client.ts` with an intraday fetcher (1m/5m via `/pricehistory`
   minute frequency) for tickers viewed in the stock breakdown; nightly + on-demand
   refresh; 30-60d rolling retention; Yahoo 1m as fallback when Schwab token is stale.
**Phase 2 — indicators**
2. Volume histogram sub-pane under the price chart (toggleable).
3. Session VWAP + developing POC/VAH/VAL from intraday bars (toggleable).
4. Estimated delta bars (tick-rule/Lee-Ready on 1m bars), clearly labeled
   "estimated" in legend + tooltip.
5. Indicator toggle panel: clean checklist UI (the reel's dark-theme clarity is the
   bar) — every overlay on/off without reload.
6. Keep the existing legend explanations (they're good); extend to new indicators.

## Out of scope
- True tick-level footprint and DOM/tape — need streaming Level 1; phase 2+ only.
- No new data vendors; Schwab (+ Yahoo fallback) only.
