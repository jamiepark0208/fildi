## Muse's analysis
First level: the reel's tradable idea is that volume-at-price marks where the market accepted value (high-volume nodes) and where it rejected it fast (low-volume nodes, single prints). Fildi already proved the first half matters for puts (S045) but never showed it to the trader. Second level: the missing half is display + TPO, both computable from bars fildi already stores — no new vendor, no new key, no new pipeline. The reel's confluence (delta + node + single prints) cannot be built as stated because the delta leg has no data; the honest version is node + single prints, with the S045 measurement as the evidence the node leg earns its place.

## Use cases (each with why + expected value)
1. **Put strike selection, visual.** At strike-pick time the trader sees on the chart whether a volume node sits between the candidate strike and spot — the same S045 signal that already scores puts, now readable instead of a bare number. Expected value: fewer fills on strikes sitting under a node; measurable after the fact through the S045 harness (node-gap puts already underperform).
2. **TPO single prints as acceptance context.** Single prints mark prices the market passed through fast (thin acceptance). A put struck under a single-print low-volume node faces a thinner floor. Display-only first: a context line on the put engine / Model List explain. Expected value: one more cheap, independent context signal at the decision point, built from bars already stored.
3. **Value area (70%) as the accepted range.** The market's accepted range, drawn on the Live chart — breakout above / acceptance back inside the value area is the trend context the Live tab's trend read currently lacks. Expected value: the trend read stops being price-only.
