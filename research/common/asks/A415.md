## Use cases (2nd-level — concrete, with why and expected value)

**Use case 1 — Explain S075's smile (mechanism test).** Fit Merton jump-diffusion (λ, jump mean μ_J, jump vol σ_J) per name/DTE bucket on LSEG option history + Schwab chains. Question: does the model-implied put price reproduce S075's observed real-mid/BS ratios (3.33× at 1–10 DTE 0.02–0.07Δ, decaying with Δ/DTE) on held-out names? Why it matters: if yes, the smile has a mechanism and far-OTM weeklies can be priced off jump params instead of a static skew table — the book's most mispriced corner (S075) gets a model. Expected value: a pricing check for put_recs on far-OTM strikes. If no, the smile is something else (liquidity/spread — S075 spreads run 29% at 1–10 DTE far-OTM) and the row stops here.

**Use case 2 — Jump-adjusted breach/tail ranker (edge test).** Score = P(breach) and expected shortfall under fitted jump-diffusion, vs S079's GBM ranker and live put edge, same walk-forward harness (expanding, 7-day embargo, test years 2022→), same decision metric (paired weekly pnl difference, week-cluster t ≥ 2, both halves > 0, breach not higher). Why it matters: S079's framing puts a better ranker at +2–4 bp/wk on picked names (~$1–2k/yr on ~$100k collateral) per +0.02–0.04 IC. A jump ranker should win exactly where GBM fails: single-name gap-downs. Expected value: challenger factor for the option score / put_recs gates (shadow first, no live change on pass).

**Use case 3 — Crash-risk gauge for the book (risk test).** Per-name jump intensity λ as a tail input: (a) to the event-stack guard (A365 condition — VIX > VIX3M + event inside expiry window) as a single-name complement to the index-level guard; (b) to the pm_alerts book-stress Monte Carlo (S017–S021, currently GBM paths) — jump paths fatten the tail honestly. Why it matters: the book's ruin case is a gap, not a drift; λ is the only number in the post that prices gaps. Expected value: a skip/shrink rule for high-λ names into events; a stress number Jamie can read before expiry Friday. Constraint from S049: test on single-name jumps — broad crashes already favor panic puts, so a λ rule that fires on broad crashes is wrong by construction.

## Pass/fail bars (pre-registered — lock before running)

- **P1 mechanism:** Merton-implied real-mid/BS ratio reproduces S075's table within ±25% on held-out names and DTE buckets. Else FAIL (mechanism not established; stop, do not proceed to P2).
- **P2 edge:** jump-adjusted ranker beats S079's GBM ranker AND live put edge on paired weekly pnl difference, week-cluster t ≥ 2, both halves of the holdout > 0, breach not higher. Else FAIL (no factor).
- **P3 stability:** refit λ week-to-week change within ±25% on ≥80% of book names; else the factor ships as UNSTABLE / NO-LIFT even if P1–P2 pass (an unstable calibration cannot gate live premium).
- **n gates:** walk-forward per S079 (expanding, 7-day embargo, test years 2022→); report n of breach/loss events per test year. Underpowered years are reported as such, not pooled away.
- **Smoke test first:** 5 names, 3 hand-checked trades (print fitted params + model price vs real mid for them) before the full run.
