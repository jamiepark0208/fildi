## Gaps: available but unused (research × inventory)

1. **Polygon — biggest gap.** A full market-data API used as a fundamentals sidecar. Unused:
   `GET /v3/snapshot/options/{underlying}` (whole chain + delta/gamma/theta/vega + IV + OI + break-even
   in ONE call), aggregates/bars, ticker details, news. This is the natural resilient second live chain
   source behind Schwab (auth-fragile, 7-day wall) — and it's already credentialed. Caveats from research:
   snapshot-only (no IV/Greeks backfill — accumulate daily yourself); 2026 rebrand to "Massive" with
   per-asset-class billing; never mirror options quotes (~120TB), mirror trades/aggs (~10GB/yr).
2. **Schwab — underused surface.** Not wired: `GET /expirationchain` (enumerate expiries),
   `GET /markets` (hours-gating — avoids weekend false alarms), `/movers`, `/instruments`.
   Trader API vs Market Data API need separate enablement; community rate limit ~120 req/min.
3. **Alpha Vantage — one OVERVIEW call.** Unused: `EARNINGS_CALENDAR`, `EARNINGS_CALL_TRANSCRIPT`,
   news-sentiment endpoint (the app hand-rolled regex news-quality heuristics instead),
   `REALTIME_OPTIONS` / `HISTORICAL_OPTIONS` — the latter (15+ years of point-in-time chains) is nearly
   unique for backtests.
4. **Finnhub — free-tier gold ignored.** Unused: `/stock/insider-transactions`, `/stock/insider-sentiment`,
   `/stock/congressional-trading` (all free tier), `/stock/recommendation`. Note: `/stock/option-chain`
   exists but users report wrong bid/ask (greeks/metadata OK) — not execution-reliable, use with care.
5. **FMP — no options endpoints at all** (fundamentals/analyst/calendar only). Unused: insider-trading
   statistics, institutional ownership, bulk endpoints (prefer bulk over per-ticker).
6. **EDGAR — good bones, room to grow.** Unused: full-text filing search, 8-K/10-Q event extraction
   (findings lib exists — verify wiring). Free, 10 req/sec, mandatory "Name email" User-Agent;
   companyfacts gives one-call bulk fundamentals.
7. **Yahoo — silent-failure mode.** 429s return empty/partial data as 200s. Must validate non-empty
   payloads; cap ~2,000 req/day, ≥200ms gaps. Still the right free keyless last resort — but never
   the lead source (see A63 ranking: Schwab > FMP/Polygon > Yahoo).
8. **LSEG — no live client.** Has a genuine volatility-surface endpoint (SVI model) but institutional-priced;
   keep offline-sync pattern; do not promise live LSEG without a contract.
9. **WRDS — research-only, no real-time.** OptionMetrics `optionm.vsurfd` (standardized 30/60/91/182/365-DTE
   ATM IV) + `opprcd` (daily per-contract IV/Greeks/bid/ask/volume/OI since 1996) is the backtest gold
   standard — wire into offline research, never the live path.
10. **Robinhood — no API.** Unofficial API gives free keyless chains with Greeks/IV/OI — fine for
    prototyping, never production. Live positions stay manual-upload per A68 (no auto-sync by design).

**Hard gaps in ALL ten sources:** dark-pool prints, borrow rates / stock-loan fees, and true
unusual-options-activity feeds are offered by none. UOA is derived (volume-vs-OI) or bought from
specialists (Unusual Whales, ORATS). Do not plan around data that doesn't exist here.

## UX gaps: used but not surfaced
- FMP/Polygon/Finnhub/AV fundamentals merge invisibly into "gold" — UI shows no source, no field-level
  provenance. User can't tell what they're looking at or why to trust it.
- FactSet referee divergences never surface anywhere.
- Schwab→Yahoo fallback is silent on some surfaces; per-bar `source` labels exist in DB but aren't
  consistently shown.
- Two analyst-action pipelines (FMP scheduler-archived tape vs 20-line Yahoo client) — neither is
  clearly primary in the UI.

## Unification (simplify, don't proliferate)
1. **Fundamentals waterfall is quota-burning.** Six sources fetch the same fields; priority-first merge
   means losers' fetches are admitted waste ("only waste quota into bronze"). Fix: rank sources per
   field, fetch in rank order, stop at first good fill.
2. **One options-chain abstraction**: Schwab → Polygon → Yahoo, per-contract source labels, single cache.
   (Polygon becomes the Schwab-outage backstop — directly serves A73's resilience goal.)
3. **One analyst-actions feed**: pick the FMP tape or Yahoo, kill the other.
4. **One earnings-history source of truth**: Finnhub vs FMP vs EDGAR currently overlap — designate one
   primary, others as gap-fill.

## Server-mode ops plan (always-on)
- **Idempotent ingest**: natural-key upserts + watermarks + raw-archive-forever (extends A63's ranked upsert).
- **Freshness SLOs**: P95 staleness budget per feed; dead-man's-switch heartbeats on every scheduled
  data job; token-age alerts (Schwab 7-day — see A73).
- **Market-hours gating**: use Schwab `/markets` / Finnhub `/market-status` so weekend runs don't page
  false alarms or burn quota.
- **Fail closed on malformed chains**; validate Yahoo payloads non-empty (429s masquerade as 200s).
- **Cache discipline**: 25s in-process chain cache or 4h-fresh/24h-stale fallback; weekly fundamentals;
  long-TTL reference data (splits, dividends, CIKs). Keep the centralized `cache-registry.ts` as the
  single choke point; add a cross-source quota allocator (today: per-client retries only).
- **Backfill automation**: after any outage, ranked re-fetch of the missed window (ties to A63 — better
  source overwrites worse).
- **No drifting processes**: single-flight/in-flight coalescing already on hot paths — extend to every
  new fetcher; every scheduled job gets a max-runtime + stale-lock breaker.

## Phasing
- **Phase 1 — resilience (highest value)**: Polygon options-snapshot chain as second live source behind
  Schwab (one chain abstraction, per-contract source labels); Yahoo payload validation; Schwab `/markets`
  hours-gating.
- **Phase 2 — UX surfacing**: source/provenance badges on fundamentals, chain, and analyst views; surface
  FactSet divergences; retire the duplicate analyst feed.
- **Phase 3 — waterfall unification**: rank-per-field fundamentals fetch with stop-early; designate single
  earnings-history primary.
- **Phase 4 — new data (cheap wins)**: Finnhub insider/congressional free tier; AV news sentiment to
  replace hand-rolled heuristics; AV historical options for backtests; WRDS OptionMetrics wired into
  offline research only.
- **Phase 5 — server ops**: staleness SLOs + heartbeats + backfill automation + cross-source quota allocator.
