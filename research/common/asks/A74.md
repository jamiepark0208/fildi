## Research headline (2025–2026 consensus: HYBRID, not replacement)
Keep deterministic logic at the execution boundary; make the *inputs* probabilistic.
Reference architecture:
1. Predictive layer → posterior predictive distribution / calibrated probability (never a bare point estimate)
2. Decision layer → P(negative outcome), expected loss, P(threshold exceedance), EV
3. Policy layer (deterministic code) → ACT / REVIEW / SKIP zones; thresholds from loss × reversibility × stake
4. Execution layer → deterministic, idempotent, audited
5. Observability layer → log prediction, interval, threshold, outcome; monitor coverage drift; recalibrate on schedule

Key results:
- Calibration: reliability diagrams at operating thresholds; Brier with Murphy decomposition
  (REL/RES/UNC, never the scalar); CRPS for distributions; PIT histograms per horizon.
  LLMs are systematically overconfident — never trust verbalized probabilities.
- Sizing: fractional Kelly (1/4–1/2 of full), p from delta/PoP, b from the *backtested* payoff
  distribution, sized on net payoff after costs.
- Regimes: HMM/MS-GARCH posterior P(regime) fed into sizing, not binary gates.
- Events: model P(actual move > priced move); IV overstates earnings moves ~15–20%; crush 30–60% overnight.
- VRP: structural edge for sellers (IV > RV ~82% of SPY days) BUT the index premium does NOT
  transfer to single names (negative in risk-off) — measure per underlying.
- Failure mode #1: gating actions on uncalibrated probabilities. Never promote an ML probability
  to a gate on irreversible actions.
- Keep deterministic: Greeks/IV math, order path, risk ceilings, cron, audit logging, compliance.

## Component assessment (repo inventory, cursor/mac-dev @ 2026-10-14)

### Migrate — highest value first
1. **Strike selection → expected value** (`lib/options.ts`, `use-top-options.ts`, `lib/option-scoring/unified-score.ts`)
   Today: hard OTM band (0.03–0.25), top-7 by score, fixed 0.5/0.3/0.2 weights, delta displayed but never used as a probability.
   Target: EV = premium × P(expire OTM) − E[assignment loss]; rank by EV per unit of tail risk.
   Weights → Bayesian model averaging over what actually predicted P&L.
2. **Position sizing → fractional Kelly** (new — nothing exists today)
   p from calibrated delta/PoP, b from backtested payoff distribution per (delta, DTE, regime) bucket;
   1/4–1/2 Kelly; VIX-regime scaling of the fraction.
3. **Model List → posterior win-rates** (`model-list-intraday.ts`, `model-track-record.ts`)
   Empirical-Bayes scaffolding already exists — extend to full posterior + credible interval per ticker;
   size/exposure from the lower confidence bound, not the point estimate.
4. **Regime → probability vector** (`regime-classifier.ts`, `intraday-regime.ts`)
   Today: 6 labels winner-take-all, pseudo-confidence from winner margin, hard VIX>30 / CPI>4 overrides.
   Target: keep the full 6-class posterior (build the A56 HMM); blend scores by class probabilities;
   overrides become probabilistic penalties.
5. **Event risk → per-ticker move distributions** (`intraday-entry-signals.ts`, `event-bullets.ts`)
   Today: hard 5-day earnings ban, ±5% bullet threshold, binary surprise sign.
   Target: historical earnings/CPI move distribution per ticker vs market-priced move (ATM straddle);
   sell the crush when EV positive; 1–2% sizing per event, 5–8% total cap; skip when IVP<50% or VIX>30.
6. **Assignment risk → P(ITM) curve** (2% moneyness band tuned 2026-10-04)
   Target: delta-implied P(ITM) over remaining DTE → live roll/close signal instead of a binary flag.
7. **Fair value → posterior** (`fair-value.ts`)
   Today: DCF+multiples voters → point estimate, 3-bucket confidence.
   Target: voter distribution → credible interval; size off P(price < fair − margin).
8. **News materiality → scored probability** (`desk-daily-news-quality.ts`, Daily News gate)
   Today: hash-compare binary, regex heuristics.
   Target: 0–1 relevance score driving brief inclusion weight; conformal/PIT-calibrated threshold.
9. **Backtesting → distributions** (`iv-rank-backtest.ts`)
   Today: deterministic replay, binary outcomes, bucket means.
   Target: bootstrap/Monte Carlo over trade sequences → drawdown + premium-capture distributions;
   regime-conditional slices (must hold in calm AND stressed).

### New areas
- **Per-underlying VRP distributions**: model (IV_sold − RV_forecast); gate entry on P(RV < IV) above a
  calibrated threshold. Measured per underlying — never assume index VRP transfers.
- **Bandit layer for online adaptation**: contextual Thompson sampling *outside* the agent, actions filtered
  through a feasibility set before exploration.
- **Conformal abstention** for news/brief triage: finite-sample bounded error rate on answered cases.
- **S/R as touch-probability zones** (`technicals-math.ts`): kernel density of historical reversals → P(touch).

### Keep deterministic (do not probabilize)
Greeks/IV pricing math, order submission path, hard risk ceilings (max loss, portfolio heat, daily circuit
breaker), cron scheduling, position accounting, audit logging, authorization.

## Phasing
- **Phase 0 — calibration infrastructure**: log every prediction with its probability, the decision, and the
  realized outcome. Nothing probabilistic ships without this.
- **Phase 1 — policies on existing scaffolding**: posterior win-rates (extends EB), P(ITM) curve, EV-ranked
  strike selection, scored news materiality.
- **Phase 2 — new machinery**: fractional Kelly sizing, event move-distribution model, regime posterior
  (A56 HMM), per-underlying VRP.
- **Phase 3 — evaluation gate** (below), then gradual production rollout with the deterministic policy
  as champion fallback.

## Evaluation: the evidence bar (pre-register before any build)
1. Pre-register hypothesis, policy logic, metrics, and bar.
2. Walk-forward with purge + embargo (embargo ≥ holding period) vs the frozen deterministic baseline,
   identical costs; or combinatorial purged CV.
3. Forecasts: Brier (Murphy REL/RES/UNC) improves or holds; CRPS improves; PIT uniform;
   interval coverage ≈ nominal.
4. Decisions: OOS Sharpe/Sortino up; max DD and CVaR(5%) not worse; **DSR ≥ 0.95**; PBO low;
   White's Reality Check / Hansen's SPA.
5. Monte Carlo drawdown distribution within risk budget; regime-conditional slices.
6. Shadow/paper-trade one full event cycle (earnings season) before capital.
