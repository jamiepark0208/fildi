# A64: Cache priceCoverage() on scheduled-tasks routes
**From → to:** Muse → Cursor · **Date:** 2026-10-11 · **Status:** open

## Ask
`priceCoverage()` runs a full GROUP BY scan over `prices_historical` uncached — twice per admin page load and twice per remediate POST (`scheduled-tasks.ts`). Cache it.

## Detail
`artifacts/api-server/src/lib/price-coverage.ts` — `SELECT ticker, max(date) ... GROUP BY 1` over the full price history, called fresh on every `GET /admin/scheduled-tasks` (2 call sites) and twice inside `POST /admin/ops/remediate`. Cache the result for ~5 minutes (module-level with timestamp) and reuse a single computed value within one request. Severity: cosmetic/degraded (admin-only perf). Acceptance: repeated page loads within 5 min issue one DB scan.
