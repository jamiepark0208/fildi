## Why it matters
Jamie is cost/token-conscious across Claude Code, Cursor, and agent workloads. If
OmniRoute can route a share of that traffic across free tiers with auto-fallback,
it cuts real API spend — but the price is signup legwork (dozens of provider
accounts) and free-tier rate limits.

## Proposal (Cursor pilots on Jamie's Mac)
1. Install OmniRoute; connect the 5–10 highest-value free tiers first (not all 150 —
   timebox the signup legwork to 1 hour).
2. Pilot (2 weeks): route one agent workload (e.g., Cursor background tasks or a
   Claude Code side task) through it; measure: actual spend saved, fallback frequency,
   latency impact, rate-limit hits.
3. Decision gate: keep it if measured savings > setup + friction cost; otherwise drop.
   Never route anything touching brokerage credentials or portfolio data through it
   (third-party aggregation = trust surface).
