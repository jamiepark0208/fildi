- **Licence:** WRDS (CRSP/Compustat/IBES), OSAP and JKP data are **research-only** (research/wrds/PLAYBOOK.md). A signal that
  passes ships only re-computed from our commercial data (LSEG/Schwab/FMP/Finnhub/Polygon). No OptionMetrics (not subscribed).
- **Two scoreboards** (pick the one the signal is for):
  - *Stock ranking* (long calls/puts, Model List names): target = `watchlist_sync.lab_outcomes` 21-day beta-residual return
    (rel_21). Weekly cross-sectional rank IC + top-minus-bottom decile spread, walk-forward, holdout 2023-01 →.

- **Harness first:** every new signal uses `analysis/lab.py signal` (stock board) or `analysis/s045_put_retest.py signal` (puts) on the cached panel before a new script. A new script only if that harness cannot express the idea.
- **PASS** = holdout t ≥ 2 (week-clustered), same sign in both holdout halves, AND marginal over the comparator
  (2-factor Fama-MacBeth or within-comparator-quintile sort, t ≥ 2). Standalone-only = "duplicates what we have".
  Verification studies (Finnhub, tastytrade, movers) report agreement instead (rank corr, % same direction, what differs).
