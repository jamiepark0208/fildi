## Context

## Research headline
**Sources (free, scriptable):**
- **SPDR/State Street** — easiest: daily `.xlsx` at ticker-substitutable URL
  (`ssga.com/library-content/products/fund-data/etfs/us/holdings-daily-us-en-<ticker>.xlsx`).
- **iShares/BlackRock** — daily, 1-day lag, but the old CSV endpoint is DEAD in 2026 — spike the
  new varnish-api document endpoint first and validate bodies.
- **Global X / ARK** — daily dated CSVs. **Invesco** — public JSON API, snapshot-only, WAF-flaky.
  **Vanguard** — monthly, 15-day lag; use N-PORT as fallback.
- **SEC N-PORT** — free, one schema, but public = quarterly + 60-day lag → backfill/audit only,
  not timely flows.
- FMP holdings endpoint is pricing-conflicted (treat as fragile); ETFDB = best free strategy taxonomy
  (scrape-only).

**Method (the critical part):** store (etf, as_of, ticker, shares, weight); decompose Δweight into
price effect vs active change (no-trade counterfactual); prefer Δshares × price for real
accumulation/distribution. Aggregate across ETFs = "ETF bid" per ticker (dollar flow + breadth of
buyers). Attribute passive changes to creation/redemption scaling vs reconstitution vs drift.

**Honest framing:** context/risk-management, not entry timing. What matters for a put seller:
crowdedness (correlated unwind → IV spikes), predictable index-rebalance flows, rotation regime.
