# A76: PM surfaces in Fildi — Book card, Expiry desk (with what-if), Alert center
**From → to:** Claude → Cursor · **Date:** 2026-10-14 · **Status:** open

## Ask
The user got no in-app warning before this week's ITM puts. Claude (portfolio manager, user 2026-10-14) now computes book risk and alerts in `scripts/watchlist_sync/pm_book.py` and `pm_alerts.py`. They need a home in the app, phone-first (the user wants alerts in Fildi, no extra app). Display only: no trading actions, no scoring change.

## Detail
**Data (Claude owns; read-only for the UI):**
- `scripts/watchlist_sync/out/pm/book-latest.json`: `{generated, snapshot_id, snapshot_at, live_priced_at, rules{crash_move, crash_budget, crash_warn, bad_week_itm}, accounts{NAME: {account, type, equity, cash, buying_power, long_value, short_puts, itm_puts, assign_if_itm_now, assign_if_all, assign_bad_week, crash_equity, crash_drop_pct, close_itm_cost, status, [margin only] maint_ratio_est, headroom_now, headroom_if_assigned, headroom_crash}}, positions[{account, ticker, strike, expiry, qty, spot, itm, move_needed, p_otm, iv, close_cost, assign_cash, days_left, status}]}`. Refreshed every 15 min on weekdays 06:00–20:00 PT (LaunchAgent `com.fildi.pm-alerts`).
- `out/pm/alerts-log.jsonl`: one JSON per line `{key, level red|amber|green, title, body, at, priced_at, emailed?}`.
- New routes: `GET /api/pm/book` and `GET /api/pm/alerts?since=` (file read with a 60 s cache; 404-safe when the files are missing). One home: don't recompute risk in TS.

**1. Book card** (top of Portfolio page and the Home/landing view; must fit a phone screen without scrolling):
- One row per account: status chip, then one plain reason line, chosen in this priority order: "Assignment → margin call −$4.6k" (headroom_if_assigned < 0), "Crash week: −69% vs 25% budget", "Assignment needs $X vs cash $Y".
- Three numbers per account: cash · assignment need (ITM now) · crash-week drop with a budget bar (marks at crash_warn 20% and crash_budget 25%).
- Footer: "priced <live_priced_at or snapshot_at>" in muted text, and stale in red when older than 1 trading day.

**2. Expiry desk** (auto-expands when any position has `itm && days_left <= 2`; otherwise collapsed under the Book card):
- Table per account: ticker · strike · needs (move_needed) · P(OTM) · close now · if assigned.
- Label under P(OTM): "market odds from the option's own IV, not a forecast".
- **What-if checkboxes** ("close this one"), recomputed client-side. Margin accounts: headroom_after = headroom_if_assigned + maint_ratio_est × assign_cash(checked). Closing doesn't change equity, because the mark is already in it; show close cost separately as cash spent. Cash accounts: cash_after_assign = cash − assign_if_itm_now + assign_cash(checked) − close_cost(checked). Show the new headroom/cash and the total close cost. This answers "which to close so assignment doesn't cause a margin call" without telling the user what to do.

**3. Alert center:** a bell in the header with an unread count (localStorage last-seen `at`), plus a list of level · title · body · priced_at. Red alerts also show a dismissible banner at the top of the app.

**Acceptance:**

- (b) Missing files → the card says "PM book not run yet", with no error toast.
- (c) Phone width (390 px) has no horizontal scroll.
- (d) tsc 0 and the test baseline unchanged.
