## Ranked findings
1. **Observed: S059 selection contaminates its holdout.** analysis/s059_option_factors.py main(), approximately lines 122–145, selects passing factors with S.fm(ev, ...) over all events. Only signs are subsequently rechecked before SPLIT. Evaluating selected factors on post-SPLIT dates is not an untouched test. Freeze inclusion/signs/weights on training data; evaluate on new dates. Test: changing holdout labels must never change selected features. Overlap: S059 and planned A191 TS shadow port. This weakens the evidence; it does not establish that the factor is useless.
2. **Observed limitation: simulated profit is not executable profit.** analysis/s045_put_retest.py build(), lines 116–157, uses IV30, a five-session synthetic strike, Black–Scholes premium and terminal intrinsic loss. The P&L formula contains no spread/fee deduction. S059 reuses it. Validate frozen picks against simple same-date/universe/risk baselines with timestamped executable bids, costs and tail losses. Stop promotion if plausible execution erases the benefit. Overlap: S045/S059 and Track Record.
3. **Observed: forward horizon differs from historical horizon.** S045 uses c[i+HOLD] (five sessions); put_edge.py log_sim(), lines 81–110, uses tt=5/252 but expires on same-week Friday. Monday-close to Friday-close is four forward sessions; holiday Tuesday is shorter. Latest-price query does not record observation date in forecast metadata. Unify the entry/expiry market-calendar contract and store data timestamps. Test Monday, holiday Tuesday and stale Friday inputs. Overlap: forecast accountability and S059.
4. **Observed in sampled path: drift warning is not automatic rollback.** put_edge.drift() returns warning strings. house_view.py main(), lines 159 onward, persists those warnings and still constructs edge_top from scores. build_plan loads scores and uses quintile eligibility. No policy state change was demonstrated here; an additional consumer elsewhere is not ruled out. Verify any enforcing consumer before claiming auto-demotion. Test an injected drift failure causes the next recommendation to use the declared fallback. Overlap: house_view/S059/A191.
5. **Observed: confidence has several meanings.** regime-classifier.ts lines 403–412 uses vote margin; fund-score-engine uses peer size and coverage; conviction-ledger confidence is ordinal 1–5. These are not interchangeable probabilities. Label agreement, data support and subjective conviction distinctly. A probabilistic claim needs outcome, horizon, timestamp, baseline and held-out accuracy. S057's direction model fails its own base-rate skill criterion; using the base rate is appropriate. Actual UI wording still needs inspection. Overlap: A74/S057.
6. **Inference: lower forecast error than IV-derived odds does not alone establish mispricing.** S057 reports failure versus empirical base-rate criteria but success versus VIX barrier odds. That comparison does not distinguish a tradable error from crash-risk compensation or pricing assumptions. Validate actual net trade utility and stress losses against an exposure-matched baseline. Keep empirical frequencies separate from model-implied odds. Overlap: S057/S049. No external literature independently checked in this folder-only pass.
7. **Observed: accountability exists; proven learning remains incomplete.** forecast_ledger.py UPSERT lines 50–57 replaces a later same-day unresolved prediction. put_edge metadata includes study/strike/spot/IV/quintile but no immutable calibration artifact identifier. This can be an intentional latest-forecast policy, but does not preserve every original prediction. Freeze evaluation forecasts with model/calibration versions and independent labels; retain revisions separately. Test exact replay and prospective champion/challenger promotion plus rollback. Overlap: A74/A124/A129; reuse existing ledger.
8. **Observed strengths worth preserving.** fund-score-engine.ts lines 330–363 shrinks sparse families and suppresses insufficient totals; street-synthesis exposes separate evidence/conflicts without mutating fund_score; model-track-record.ts lines 233–234 requires live bids and lines 277/303 avoid duplicate snapshots; conviction-ledger supports explicit metric/date/price kill rules. These support disciplined decisions and abstention. Validate missing-data/stale-quote/conflict behavior end-to-end. These selected controls do not certify the whole application.
